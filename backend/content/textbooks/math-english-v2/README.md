- 严格保留实际可见册次；缺少下册、六年级或某些版本时不补造。一二年级英语在本次官方目录筛选中未展示，不据此断言学校不开设。

- 全部 `index_only`、`rightsReview.pending`、无单元/课次。未下载教材封面、正文、插图或题目；导入不触发课程生成或发布。
