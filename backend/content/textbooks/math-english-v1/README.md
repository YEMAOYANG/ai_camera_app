# 数学、英语教材版本索引

> 本目录是首批 65 册。2026-09-28 的完整复核和新增 216 册见 [`math-english-v2`](../math-english-v2/README.md)，部署时两批一并导入。

2026-09-28 从[国家中小学智慧教育平台公开教材目录](https://basic.smartedu.cn/tchMaterial)按“小学 → 学科 → 版本 → 年级”逐项核对。来源编号来自对应书目公开展示的官方封面资源路径，每个 JSON 保存其官方详情链接。仅收录书目信息，不下载或分发课本正文、插图、题目。

| 学科 | 版本 | 年级、册次 | 数量 |
| --- | --- | --- | ---: |
| 数学 | 人教版、北师大版、苏教版 | 一至六年级，上下册 | 36 |
| 英语 | 人教版（主编：吴欣） | 三至六年级，上下册 | 8 |
| 英语 | 人教版（主编：苗兴伟） | 三至四年级上下册、五至六年级上册 | 6 |
| 英语 | 外研社版（主编：孙有中） | 三至五年级上下册、六年级上册 | 7 |
| 英语 | 译林版 | 三至六年级，上下册 | 8 |

共 65 册，均为六年制小学。没有推断或补造未展示的册次；本批未包含一、二年级英语、五四学制数学/英语和其他出版社版本。界面允许跳过缺失学科并继续保存已选教材。

版本与资源编号独立保存，英语同一出版社的不同系列不可合并。官方标题明确标注按 2022 年版课程标准修订的册次保留该标识；没有该标识的下册不推断为新课标版本。全部为 `index_only`、使用依据 `pending`、课次为空；选择不代表课程已发布，也不触发生成。

校验（不连接数据库）：

```sh
backend/.venv/bin/python backend/scripts/textbooks.py validate-catalog backend/content/textbooks/math-english-v1
```

部署已有教材表的环境时显式导入，读取目标环境已配置的数据库连接（不会建库或迁移）：

```sh
backend/.venv/bin/python backend/scripts/textbooks.py import-catalog backend/content/textbooks/math-english-v1
```

导入由原有事务实现，可重复执行；相同版本内容有冲突时整批回滚，不覆盖既有修订。
