# 外研小学英语版本核对与补齐

2026-09-28 根据教育部审定目录、外研社系列介绍和国家中小学智慧教育平台公开元数据，核对库中全部 32 册外研小学英语。GitHub 不作为本次身份核验依据。

本目录包含 48 份新增修订：32 份书目信息修正，以及陈琳主编三年级起点 8 册的书目和目录各一份。核对后的外研教材共 40 册，每个版本仍有独立的教材身份。

## 核验依据

- [教育部 2024 年义务教育国家课程教学用书目录（2022 课标修订）第 5 页](https://www.moe.gov.cn/srcsite/A26/s8001/202408/W020250418502592948423.pdf)：刘兆义、张祖春、孙有中三个小学英语系列均从三年级上册起。新教材的“三年级起点”是依据完整审定系列作出的规范化分类，未冒充国家平台原始书名中的字样。
- [外研社一年级起点系列](https://www.unischool.cn/cpzy/kbjc/nse1l/)、[陈琳三年级起点三上](https://www.unischool.cn/c/2016-05-05/72398.shtml)、[Join In 三年级起点系列](https://www.unischool.cn/cpzy/kbjc/joinin/)：明确旧系列的起点和 2011 课标体系。
- `../sources/fltrp-edition-audit-20260928.json`：32 册原始标题、官方标签、资源编号、逐册身份、原修订摘要、规范化标签和依据。
- `../sources/smartedu-sync-fltrp-three-year-20260928.json`：陈琳三年级起点 8 册的精确来源白名单，包含官方索引版本、年级、册次、主编及目录 ID。
- `../sources/smartedu-directories-20260928/`：新增 8 份目录快照，保留官方节点、层级和次序。

20 册原电子教材逐册回查均为 `ONLINE`；12 册原一年级起点同步课堂目录逐项比较与既有快照一致。新增陈琳三年级起点三上首课为 `Unit 1 I’m Sam.`，一年级起点三上首课为 `Unit 1 Do you use chopsticks in the UK?`，两者没有合并。

新增同步课堂目录共 276 个末级节点，其中含模块复习和复习单元。这是平台教学目录的粒度，不等于教材正文课数，也不代表课件已生成。新增课件任务书保持草稿，内容使用依据仍待审核。

## 修订与应用

既有文件与数据库修订保持不可变。`20260928-metadata-1` 只改变显示标签和修订号，原目录、官方来源、节点、教学任务书和使用依据保持原样。新选书目录展示新修订；已保存的选择仍使用原修订。

`content/textbook_metadata.py` 对已核验的同一教材身份提供名称修正，让已有选择也能显示准确的起点、主编和课标版本。该映射同时校验教材 ID、官方资源 ID、出版社、学制、学科、年级、册次和既有标签；不改写绑定与历史。

沿用 `mira.learning.textbooks.v1` 和现有家长选书、学生目录 API，无字段或数据库结构变更。同步课堂清单校验只增加这 8 册精确记录，不放开任意来源。

```sh
backend/.venv/bin/python backend/scripts/textbooks.py validate-catalog backend/content/textbooks/fltrp-reviewed-v1
```

部署教材时，在确认目标、备份并核验后使用现有 `textbooks.py import-catalog` 导入本目录；启动后端不自动导入。不要覆盖旧文件或直接修改修订 JSON。
