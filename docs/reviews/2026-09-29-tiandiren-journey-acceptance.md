# 《天地人》自主学习闭环验收

本记录接续同日 OpenMAIC 原生接入验收。适用范围是已发布《天地人》这一节课；其他教材不会自动获得这套活动。继续从学生端教材目录进入原 OpenMAIC 课堂，没有新增独立网页。

## 学习流程

1. 先用六题了解孩子会哪些字，保留首次结果；已会内容跳过重复讲练。
2. 对不会或需要帮助的字安排拖字找图、人物点击与说话人切换；提示分三层，最后提供示范。
3. 换到操场、雨后、郊游等新情境独立回答。提示、老师帮助和大人帮助均不能算独立掌握。
4. 错题进入原因追问、针对性练习和另一道新题验证。连续困难时暂停并提示家长短时介入，不靠重复点击判为掌握。恢复后继续使用未见过的题。
5. 六项独立通过后，在现有 tasks 模块安排隔日复习；通过后安排七天后的复习。服务端控制到期时间，重玩不提前完成复习，不覆盖首次成绩。
6. 学生书包显示继续学习和到期复习入口；家长摘要展示首次表现、独立通过项目、待巩固内容、复习时间与必要的介入建议。结束可返回书包。

原讲解、老师、同学、讨论入口保留。活动状态、报告和复习任务保存在既有学习会话、报告及任务结构中，无数据库迁移。原发布媒体、课程哈希及旧成绩保持原记录。

## 配音修正

最初新增的活动音频使用 macOS Tingting 预生成，用户指出音色问题后，改为通过项目已有 OpenMAIC 正式语音接口制作 Qwen3 TTS Flash／Serena 配音。新题、提示和反馈共 180 段、4621 字，共享已保存音频；学生点击播放不触发新的生成请求。

生成脚本冻结文本和教师身份，保存每段回执，并验证 WAV、时长和哈希。完整包就绪后原子替换清单；无浏览器合成或系统语音降级。原请求失败或状态不明时不会自动重发；明确的 Provider 拒绝可通过指定原请求的操作参数做一次有记录的修复。

## 验证

- 后端 60 项测试通过。隔离状态及真实仓储 SQL 测试覆盖分流、三层提示、错误追问、补练、新题独立验证、暂停恢复、首次成绩保护、隔日/七日复习和任务幂等；音频测试覆盖中断不重发、部分失败不覆盖清单及教师音色绑定。
- 复习到期使用受控时钟验证；没有等待真实七天，也没有改写真实孩子的成绩。
- Gateway 固定教材接口测试通过，覆盖未授权拒绝和音频转发。
- Student Web：lint、类型检查、257 项测试和生产构建通过。
- Flutter：analyze 无问题，全量测试 374 项通过、1 项跳过。
- OpenMAIC：活动组件定向 lint、生产范围类型检查及生产构建通过；补丁 0132 已登记并完成反向校验。全仓包含旧测试夹具的类型检查仍有既有错误。
- 浏览器已验证原课堂入口、活动新情境、老师/同学控件及实际音频请求。新配音切换后，原页面直接点击“听一听”进入“暂停声音”播放态，音频接口返回 200。
- 180 段音频全部安装，逐段核对原 TTS 记录、文本 SHA、声音身份、音频 SHA 和非空 WAV：均为 `qwen-tts / qwen3-tts-flash / Serena`，没有降级声音。首次请求 179 段成功、1 段明确 `provider_rejected`；该段保留失败原回执，通过一次指定修复成功，合计 181 次 TTS 请求。未追加 ASR 调用，不能将本次配音验证表述为逐句 ASR 审核。

真实儿童的学习效果尚未验证；本次未实现朗读发音评分、手写笔画评分或将样板自动扩展到全国所有课文。
