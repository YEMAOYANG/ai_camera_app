# 学生端教材同步、版权边界与自主学习价值审核

审核日期：2026-09-28。目标：减少家长辅导时间，让孩子通过有趣、有效的互动独立提高。

基于当前 `codex/fixed-textbook` 工作树，HEAD 为 `cfd9d60`，包含本轮开始前已有的大量未提交变更。本轮新增审核报告与截图，没有修改业务实现、教材选择、学习记录、数据库结构或发布状态，没有调用付费模型。历史记忆仅用于定位检查入口，以下现状结论均来自本轮代码、元数据、浏览器观察或专项检查。

**结论：教材同步可以继续作为内容定位基础。当前项目已经具备教材目录、共享课件、图画导学、课堂互动和服务端判题，但新教材主流程还不足以证明孩子可以自主查漏补缺。下一阶段应围绕“会的少学、卡住能获助、换题仍会、过几天仍记得、家长只处理必要例外”建设。**

“比现实课程更有优势”应先限定为课后场景：随时获得针对性帮助、按掌握情况调整练习、减少家长重复解释。学校教师也会采用这些方法，数字产品是否提供了额外收益，需要家庭试用与学习结果比较；当前没有足够证据宣称整体优于学校课堂。

## 1. 教材同步与原创内容的版权边界

按中国大陆法律进行产品风险分析，不是对特定课程是否侵权的法律裁定。

独立讲授通用知识、公式和能力目标，与复制教材中的具体表达，是不同的使用行为。著作权法同时保护符合条件的作品、改编以及具有独创性的选择和编排；学校教学、个人学习等例外也有适用条件，不能直接推导出面向家庭的商业 App 可以自由分发教材内容。参见[著作权法第三、五、十三、十五、二十四条](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html)。

| 做法 | 本次风险判断 | 建议的产品处理 |
| --- | --- | --- |
| 根据通用知识目标独立设计故事、例子、图画和题目 | 相对较低，但仍须核验素材及生成结果 | 保留创作记录、素材来源和教研审核 |
| 用少量版本和课次信息帮助家长定位 | 不能仅因属于“元数据”就判断全部可自由使用 | 明确实际展示范围和使用依据 |
| 整册照搬目录、章节顺序与教学材料的选择结构 | 是否使用了受保护的编排，需要具体分析 | 商业发布前针对实际页面、目录和课程核对依据 |
| 换词改写课文、把原题换数字、重画相似教材插图 | 表面变化不能自动解决权利问题 | 改为从知识目标独立设计，或取得覆盖具体用途的许可 |
| 展示课文、教材页面、原版封面、插图、录音 | 需要逐项确认许可或其他适用依据 | 不把平台可读、GitHub 可下载当作商用授权 |
| 将教材材料提交模型、生成配音或向用户传播 | 输入材料的使用与输出传播需分别核对 | 素材依据应标明允许的用途和范围 |

国家版权局 2003 年的教辅意见既谈到编排保护，也要求对义务教育配套教辅具体分析。因此，不能仅据“同步目录”认定必然侵权，也不能仅据“正文原创”认定必然安全；该意见针对教辅图书，不能直接作为本 App 的免责结论。[国家版权局意见](https://www.ncac.gov.cn/xxfb/tzgg/200312/t20031229_50191.html)

- [普通制作入口](/Users/sqcopenclaw/Desktop/ai_camera_app/backend/content/textbook_catalog.py:236)要求整册使用依据和本课目标通过；[已保存课件发布入口](/Users/sqcopenclaw/Desktop/ai_camera_app/backend/services/textbook_publication_service.py:59)另用单课审核合同。这种分层本身不等于漏洞，也不等于整册已获得授权。

建议在商业分发前完成一次具体权利核对：把实际目录页面、一节完整课件、所有素材来源和拟使用方式交由版权专业人士审阅。代码层面将“我们同意发布”与“材料使用依据已核实”分别记录；依据可以是自主创作、适用许可或经审阅的其他合法依据，不能只保存一个通过标记。记录应覆盖素材、使用方式、适用版本、期限及依据文件。无需为了规避问题擅自改掉孩子需要的教材对应关系。

## 3. 当前功能与目标的差距

| 能力 | 当前核实的实现 | 对目标的判断 |
| --- | --- | --- |
| 教材版本与家庭选择 | 真实目录、选择历史、版本约束和按孩子授权 | 可保留，是定位基础 |
| 固定课程生产和复用 | 审核发布后共享内容，学习记录按孩子分开；打开目录不生成课程 | 可保留，避免每个孩子重复生产整课 |
| 图画与语音导学 | 四步探索、图片选择、预制语音、重听、字幕 | 已有可用入口，可保留自由探索属性 |
| 课堂对话与白板 | 固定教材合同仍允许讨论、语音识别、语音回复与白板动作 | 代码具备能力；本轮未发起付费对话检验质量 |
| 课堂测验和报告 | 服务端按固定单选题判分；保存首份提交、练习报告和完成状态 | 是作答记录基础，尚不足以评价持续独立掌握 |
| 摸底、路径与专项练习 | 旧代码存在，教材默认模式拒绝相关旧 API，路径和练习页回到书包 | 当前主流程未承接这些能力，不能用旧模块存在证明新模式已自适应 |
| 按错因补救和延迟复测 | 本次审阅的新教材链路未见对应调度 | 是减少家长重复讲解的关键缺口 |
| 家长学习入口 | 展示选书、课程开放及完成比例，并保留观察确认入口 | 还不能清楚回答“今天哪里已独立解决、哪里需要我介入” |

以下问题应优先处理：

**P1：新教材主流程缺少学习决策。** [学生 API 边界](/Users/sqcopenclaw/Desktop/ai_camera_app/backend/routes/api/v2/student_textbook_boundary.py:11)停用旧摸底、路径、练习和学生报告列表；[专项练习页](/Users/sqcopenclaw/Desktop/ai_camera_app/student-web/src/app/learning/practice/page.tsx:3)直接回到书包。新入口尚未提供基于证据的替代流程。解决方式应复用可用的学习评价能力并接入教材身份，不能直接恢复旧的学生触发整课生成流程。

**P1：完成课程与掌握知识尚未形成决策关系。** [课堂完成条件](/Users/sqcopenclaw/Desktop/ai_camera_app/backend/services/textbook_classroom_service.py:171)使用页面访问、讲解动作结束和已提交测验；完成并不要求答对，也没有据此安排纠错任务。这可以作为“完成一次学习”的定义，但不能用完成比例替代掌握。固定发布分支在[课程可用性检查](/Users/sqcopenclaw/Desktop/ai_camera_app/backend/services/textbook_learning_service.py:203)中校验发布合同后返回，没有进入下方旧课程的先修判定。当前没有证据说明固定教材课已经接上细粒度先修和跳过逻辑。

**P1：不能据当前报告判定孩子独立完成。** [测验和报告](/Users/sqcopenclaw/Desktop/ai_camera_app/backend/services/textbook_classroom_service.py:244)将提示使用写为 false、提示数写为 0，并把正确数同时作为独立正确数；掌握等级固定为 `developing`。保守等级避免把选择题直接宣称为朗读达标，但未记录是否得到提示、讨论或家长帮助，独立正确数还缺少实际依据。

**P1：练习反馈没有转成孩子下一步能执行的任务。** 当前错后报告建议重听解析；全对时建议与家人指图表达。[报告代码](/Users/sqcopenclaw/Desktop/ai_camera_app/backend/services/textbook_classroom_service.py:265)没有生成补救任务、新的独立题或延迟复测。家庭交流可以保留为可选活动，不应成为所有孩子完成学习的默认依赖。

**P1：互动参与缺少可用的学习证据。** 当前[进度接口](/Users/sqcopenclaw/Desktop/ai_camera_app/backend/services/textbook_classroom_service.py:186)返回空的互动目标完成列表。[现有角色游戏源码](/Users/sqcopenclaw/Desktop/ai_camera_app/backend/content/textbooks/reviews/tiandiren-storybook.v1.html:18)已经有说话人切换、正误反馈和错选重试，这是有教学意义的互动；但这份游戏代码未见按知识点回传首次尝试、提示、错因和迁移表现的机制。可以保留游戏乐趣，同时补充正式练习证据；自由导学不需要强行评分。

**P2：课件规则尚未形成统一的教学验收。** [分年级规则](/Users/sqcopenclaw/Desktop/ai_camera_app/backend/content/textbook_pedagogy.py:5)规定文字量、视觉比例、语音长度与回应方式，[预览检查](/Users/sqcopenclaw/Desktop/ai_camera_app/backend/content/textbook_preview.py:62)主要检查场景类型、配音、图片和六道题等结构，并明确要求继续人工审阅。不能用结构齐全或 TTS 识别相似度替代教研质量、儿童理解或儿童发音评价。

## 4. 减少家长辅导时间，应接走哪些工作

家长的时间主要花在决定学什么、读题解释、发现错误、反复讲解、监督继续和确认是否会了。产品要逐项承接这些工作，家长只处理持续困难、无法判断的表现以及必要的家庭交流。

| 家长现在承担的工作 | 建议的学生端行为 | 验收应观察什么 |
| --- | --- | --- |
| 每天选课 | 根据已确认学校进度、当前证据和待复习项提供一个可说明理由的建议；也允许自主选书 | 能否独立开始；不把低年级历史缺失当作不会 |
| 读题、解释操作 | 低龄任务可以听、看、点；一次一个操作；听不清可重播，不能依赖会拼音 | 家长因操作或读题介入的次数 |
| 查错、讲错 | 区分看错要求、概念误解、步骤缺失和偶发失误；用小追问验证猜测 | 不因一次错题给孩子贴标签；补救是否对准问题 |
| 一遍遍重讲 | 提示逐步增加：指出关注位置 → 给具体例子 → 分步示范；随后撤掉帮助 | 提示后能否独立完成新问题 |
| 盯着做完 | 有明确的小任务、即时反馈、进度和自然结束点；连续受挫可暂停或换更基础的支撑 | 自主完成率、放弃点、无效重复时间 |
| 判断有没有学会 | 用不同情境的新题和延迟复测观察；区分看过、练过、独立完成、延迟保持 | 过几天的新题表现，不能只看课堂内正确率 |
| 看报告再安排 | 家长只看到解决了什么、仍卡在哪里、是否需介入、系统下一步安排 | 阅读和处理报告的实际时间 |

推荐流程：确认当前课内范围 → 少量互动了解现有表现 → 已会的缩短或跳过 → 对具体卡点短讲解和操作 → 撤掉提示做新题 → 后续间隔复测 → 家长收到必要结果。少量诊断只是初步证据，不应让两三题决定长期标签或永久解锁；出现矛盾证据时补充观察。

内容仍可共享，个性化发生在选哪个任务、给什么支撑、何时再练以及何时结束。无需为每个孩子即时生成整节课。学校进度未知时如实标明，允许孩子或家长简短确认，不把“选择了某本教材”当成“已经知道学校今天教到哪”。

技术上延续现有学生身份、固定教材合同、课程版本、任务及报告系统；教材节点映射到稳定知识点，后端记录首次作答、帮助来源、提示级别、错误类型候选和题目版本。下一步和复习任务继续属于 `tasks`，不新增 `daily_flow` 或 `daily_plan`。更改代码前需要另行形成接口与文件变更方案，本报告不代表这些能力已经实现。

主动回忆、间隔复习和解释性问题有学习研究支持；数学的具体操作材料、系统示范和表达也有相应研究依据。它们支持候选设计，不能证明 Mira 已有效或优于学校。[IES 学习与复习指南](https://ies.ed.gov/ncee/wwc/PracticeGuide/1)、[IES 小学数学干预指南](https://ies.ed.gov/ncee/wwc/practiceguide/26)。数字技术的价值应落在教学、练习和评价质量上。[EEF 数字技术指南](https://educationendowmentfoundation.org.uk/education-evidence/guidance-reports/digital)

## 5. 互动和趣味应成为课件验收要求

保留书包、人物、图画、语音和自主探索。进一步让孩子能够作决定、看到决定的后果、修改尝试并发现规律。每节课不必都做 3D，但需要有与教学目标对应的实际活动；空间关系适合 3D，认字、数量或简单比较常可用更直接的表达。

| 学科示例 | 有教学作用的互动 | 应检验的学习结果 |
| --- | --- | --- |
| 语文“你、我、他” | 切换说话人，让孩子指角色、接话或用角色说一句话 | 人物位置或说话人改变后仍能判断 |
| 数学数量与分组 | 分物品、拖放组合，先猜结果，再操作比较 | 撤掉操作提示，换一组对象仍能解释和解决 |
| 英语交际 | 在小商店或问路情境中完成明确任务，选择会影响对方回应 | 换商品或人物仍能完成交流；不只背同一句话 |
| 科学探索 | 预测 → 改变一个条件 → 观察变化 → 解释 | 能说出证据；区分模拟结果与现实实验结论 |

每个正式互动至少验收六件事：有明确目标；儿童确实参与；动作带来与知识相关的变化；错误后获得具体支撑；允许安全重试；最后有撤掉提示的验证。兴趣导学可以保持开放式探索，不应把所有选择都变成考试。

课件检查还应覆盖错误选项、连续错选、随意点击、重播、退出恢复、没有麦克风、音频失败和减少动效。不能只检查“有游戏页”，也不能把所有选项都鼓励为正确。语音识别不确定时允许重说或改用点击，不把识别失败计作知识错误。

一年级样板可直接扩展现有《天地人》：先用不提示答案的情境了解认字和角色理解；熟悉的部分略过；卡住时使用同一套原创角色图逐步提示；换说话人和新场景独立检验；后续再给短复习；向家长说明观察到的能力和未评价的朗读、书写部分。游戏成功与正式独立证据分别记录，防止多次试选把答案记住后被当作已掌握。

趣味要与学习效果分别评价：儿童愿不愿意开始、理解操作需要几次成人帮助、在哪一步失去兴趣，以及新题和延迟复测表现。在线时长、动画数量、点击次数和奖励领取不能代替这些指标。

## 6. 实施顺序和试用验证

| 顺序 | 工作包 | 可以审查的完成标准 |
| --- | --- | --- |
| P0 | 确认首批课件的权利依据与教研目标 | 每项素材和教材对应有依据；老师核验目标、常见误解和独立题；不得仅由模型自评通过 |
| P1 | 做出一节从进入到复习的完整样板 | 已会可缩短，错后有分级帮助，帮助后有新题，学习状态不等同于播放完成 |
| P1 | 接入独立证据、补练及延迟复测 | 提示/协助如实记录；服务端选择后续任务；学生和家长看到一致结果 |
| P1 | 简化家长介入 | 一次基本配置后可自主进入；报告有明确介入条件；不把常规检查全交回家长 |
| P2 | 扩展为一个小单元和可复用互动模板 | 连续几课都有合适下一步；语音和游戏错误分支经过审核 |
| 后续 | 依据试用结果扩年级与教材版本 | 先证明局部学习价值，再投入大规模课程生产 |

建议先做小规模可用性试用，再做学习效果比较。试用时保持学校学习、内容难度和可用时间尽量可比，采用不同但等值的题目，记录初始水平及家长介入。可将“原有固定讲解流程”与“诊断、支撑和复测流程”比较；若采用家庭交叉体验，要安排不同知识点并注意先学内容带来的影响。小样本用于发现方向，不能包装成已证实的提升比例。

同时观察：家长实际辅导分钟数（包括配置、处理故障和看报告）、儿童无成人帮助完成的比例、无提示新题表现、次日及一周后保持、反复受挫和退出比例、儿童是否愿意再次参与。家长时间下降而学习变差，或成绩上升却依靠更多成人帮助，都不算完成本次目标。

可以在试用前共同设定候选目标，例如“在新题表现不下降的条件下，降低家庭辅导时间”，但本轮没有真实家庭试验，不给出已经节省多少时间或提高多少成绩的数字。
