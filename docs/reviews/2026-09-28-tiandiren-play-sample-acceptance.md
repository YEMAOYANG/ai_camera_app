# 《天地人》互动样板验收

2026-09-28。本次新增独立可运行样板及学习证据状态机，未修改原发布版本、正式教材入口、真实孩子记录、业务数据库结构或其他已存在的工作树变更。

## 可体验的结果

- 图片探索：点天空、地面和任意一位孩子听字音、看对应汉字。
- 拖字找图：字牌可拖动，也可直接点图；错误不通过，方向提示后仍需作答，二级提示才示范区域。
- 小小配音员：孩子主动切换说话人，再切我、你、他，看对应人物变化。随后完成六轮固定挑战。
- 独立挑战与补练：可直接挑战以缩短已经会的内容；首次作答、提示、成人帮助分别保存。只补练需要帮助的目标，再做不同情境的题。
- 完成、再玩与复习：复玩不修改首次结果；服务器计时 24 小时后才解锁实际复习。提前体验使用已经出现的情境，避免预先暴露次日题。
- 家长反馈：逐字列出第一轮、新情境和隔天复习的证据，以及简单的下一步。不声称识字选择题能证明朗读、书写或长期掌握。

## 实际验证

| 范围 | 结果与边界 |
| --- | --- |
| 确定性教学与持久化 | `test_textbook_sample.py` 21 项通过。涵盖角色变化、游戏错误不可继续、两级提示、首次记录不可替换、按需补练、复玩不覆盖、服务端复习时限、不同会话隔离与幂等重试。 |
| HTTP 与素材 | `test_textbook_sample_http.py` 5 项通过。临时库、临时本机端口；验证 Host / Origin、私有题库不可读、未答题答案不返回、重复提交和媒体字节摘要。 |
| 素材 | 清单 102 项：1 幅原创插画、49 段已审阅旧录音、52 段新增本机参考配音。101 段音频均有有效帧、时长及非恒定采样；这不是新的 ASR 或发音质量终审。 |
| 浏览器正常流程 | 真实页面走完探索、三轮找字、六轮角色、六题初测、针对性补练、六道新情境、完成页与家长页。随后对最终修订题面走完“直接挑战”及新情境 12 题，体验复习后家长页隔天证据仍为空。 |
| 浏览器错误分支 | 故意错选、用提示、标记成人帮助。页面区分首次独立、帮助后答对、首次错误，补练后没有重写原记录。实际拖动字牌可通过；复玩入口可重新进入探索。 |
| 恢复 | 刷新出现继续入口；暂停样板服务后操作显示恢复按钮，未确认操作没有推进。重新启动样板服务，恢复原题后继续。 |
| 视觉 | 桌面 1280×800、平板横屏 1024×768、手机 390×844 检查；无横向内容溢出。关键交互为至少 48px 触点，支持键盘点选；最终页面控制台未采集到脚本错误。 |

JavaScript 语法检查、Python 编译及 `git diff --check` 通过。初次使用系统 Python 的编译缓存被沙箱拒绝，改用项目虚拟环境后编译通过；没有修改系统权限。首次本机语音在沙箱中得到空音频，被准备工具拒绝；允许该本机语音进程后重新生成并通过素材检查。

没有改动 Next.js 或 Flutter，因此没有为此样板运行它们的全量构建。没有商业发布、正式业务库写入、付费 Provider 调用、真人儿童效果试验、真实触屏设备操作测试或新的专业教研签审。次日时限及到期后作答通过可控服务端时钟测试，未声称实际等待了一天；浏览器只体验了提前预览。
