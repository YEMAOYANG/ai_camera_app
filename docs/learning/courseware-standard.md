# 课件制作标准（唯一标准）

适用于所有新做的课件（各科、各年级）。它取代 `low-reading-interaction-rule.md`、`backend/content/textbook_interaction_policy.v1.json`、`backend/content/textbook_courseware_quality.v1.json` 和 `backend/content/low_reading_policy.v1.json`。已发布的旧课保持原样；这些旧文件只在旧课还需要校验时保留，不得用于新课件，旧课退出时一起删除。

## 一、做课前

1. **读官方资料。** 国家中小学智慧教育平台对应教材版本、年级、册次、课次的教学设计、课件、学习任务单、课后练习（视频可豁免，用户 2026-10-30 已批准）。只取"教什么、教到什么程度、练什么"；画面、台词、题目一律原创，不搬原文。
2. **写 `official-notes.json`。** 每类资料的目标、重难点、课后练习，带页码引用。没有笔记不开工（闸门 G0）。
3. **写简要稿 `brief.json`。** 目标 / 页序 / 每页玩法 / 小检查题 / 课后练习去向。页数按目标定，不凑数。

## 二、页面

4. **讲解页**：画布 1000×562.5，文字框互不重叠、不出画布，一页一件事。
5. **互动页**：逻辑画布固定 1280×720、铺满，统一用公共框架 `courseware/kit`：开始页（本课插图 + 一个开始按钮）→ 关卡点 → 星星 → 音效 → 逐级提示 → 第一次答错不报正确答案 → 完成页；图片加载失败有后备；按钮可点区域 ≥44px。
6. **不放“课堂讨论”指令（discussion）**：它现场调用付费模型（本机付费课堂互动是关着的），学生端也只接待自己名单里的同学，一二年级孩子更无法输入。想请孩子思考的问题，写成同学提问的老师台词，如“小满问：……说给大人听”，用老师预录音读出（G3）。
7. **老师真正讲课**：每个学习目标都要在老师的话里讲清楚：用孩子听得懂的话解释概念，给一个具体例子并说出每一步为什么，说出规则或要点；只会说“看这里、点一点”、念图上的字，不算讲解。讲解页至少 6 句、100 字，互动页至少 5 句、90 字（《整理和复习》平均 160 / 130 字，一般 8–10 句）。每个互动页老师至少 3 次操作画面（高亮 / 批注 / 揭示 / 设状态），目标元素必须真实存在，示范时边操作边讲为什么，再交给孩子做。老师每句话尽量 ≤25 字，讲解句和儿歌最长不超过 40 字（26–40 字只警告，超过 40 字不能上架）。猫头鹰、小满、朵朵可以用自己的声音提问、提醒、总结（句首必须报出名字，因为没有头像会亮起），不替老师讲必须讲的话，不抢答小检查。最后一页回顾本课的知识点。
8. **玩法由本课目标决定**，不套模板；孩子的操作要改变画面里的对象，不是只换文字和分数；相邻页机制相同要说明理由。
9. **一二年级不靠认字就能玩**：情境图、图片选项、老师读题；被教的字和拼音可以放大让孩子认；emoji 不能代替有意义的图；遮住非目标文字，孩子仍能听题、分辨图片、作答并继续。

## 三、声音和教材

10. **声音按角色性别**：小数老师男 Ethan，站长猫头鹰女 Cherry，小满男 Aiden，朵朵女 Bella，其他学科以教师档案为准。每句老师的话都有预录音，不叠音、不截断，不用浏览器机械音。
11. **教材准确**：每句老师的话和每道题对照教材核对（儿歌、口诀、符号方向逐字核）。独立核对员（另一个模型）逐句核台词、逐题从头重解，有分歧交人裁决。

## 四、小检查和家长端

12. **小检查**：选项为图片（一二年级）、按教师性别配音读题、每题标知识点 `skill`、有解析、唯一正确答案、不出现"请你自己读题"。题目用新数字、新情境，不重复课上讲解和游戏里练过的例子（那是背例子，不是检查）；正确答案不能集中在同一个位置（超过一半不过，G4）。答题写入学习证据，家长端出报告和薄弱点。
13. **每周测题包**：每课只交"题源"（学习目标、课后练习要点、小检查的知识点，已在 `official-notes.json`、`brief.json` 和小检查里），不单独出测验。每周把孩子这一周学过的所有课合在一起，一次生成一份约 30 分钟的周测：每个学习目标约 2 题原创变式，图片 + 老师配音，独立核题，存档 MinIO，周末推送；没学的课不出题；题量不足如实显示，不凑题。
14. **证据口径**：点击、听完、选对 ≠ 会读会说；报告只写观察到的，口语、纸笔等没有观察到的写"待观察"。

## 五、上架

15. **自动闸门**，`publish_courseware.py check` 全过才能上架：

| 闸门 | 检查什么 |
|---|---|
| G0 | 官方资料笔记齐全，带页码引用 |
| G1 | 每句老师的话都有音频，文件存在、文件名里的哈希对得上，无多余或缺失媒体 |
| G2 | 讲解页文字框不重叠、不出画布 |
| G3 | 互动页铺满 1280×720；老师每页 ≥3 次操作，目标在页面里真实存在；讲解量：讲解页 ≥6 句且 ≥100 字，互动页 ≥5 句且 ≥90 字；页面自己的元素编号不得与公共框架的编号重名（如 dots、hud、say）；台词、讲解页文字、小检查文字、官方笔记不含繁体字（课件一律用简体） |
| G4 | 小检查：唯一答案、有解析、有 `skill`、有读题音频；一二年级选项是图片；正确答案位置不集中 |
| G5 | 每个角色的声音与性别表一致 |
| G6 | 三种尺寸（1280×720 / 1000×563 / 640×360）脚本试玩：无 JS 报错、无重叠、无截断，可点区域 ≥44px；随机试玩机器人：每个互动页都能点着拖着通关，点“再玩一次”能复位；通过后留回执 |
| G7 | 独立核对：台词与教材一致，每题重解答案一致，`skill` 与本课目标对应；逐个学习目标核对老师的话里是否真的讲了（讲了 / 讲得薄 / 没讲，后两种不能上架） |
| G8 | 发布包字段齐全且如实，并通过学生端校验 `validate_release` |

16. **一条命令上架**；发布包字段如实（所有者确认原话 + 自动检查摘要），不伪造人工听验；同一课时旧版自动下架（保留可回退）。
17. **缺陷变闸门**：抽检发现的每类缺陷，必须补成一条自动检查或本标准里的一句话，才算修好。

## 六、不再要求

冻结合同、官方复盘追溯、逐页进度保存适配器、多层审核记录、固定页数、玩法配额和固定页型顺序。产品底线保留：先读官方资料再原创；不把点击说成"会认会读"；不泄露答案、不惩罚第一次答错。

## 七、随旧课退出时删除的遗留

旧课退出后，下列内容连同它们的测试一起删除：上面四个旧规则文件、旧制作与上架链路、每课专属的校验与互动适配器。具体清单在清旧阶段由引用图算出后补记在这里。
