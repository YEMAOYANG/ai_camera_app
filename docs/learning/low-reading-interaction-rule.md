# 一、二年级图像优先交互规则

用户在 2026-09-29 明确要求：一、二年级默认不能独立读懂文字，大多数游戏、课件、问题和答案都要用多图表达。这是跨学科、跨生成课件与手写课堂组件的产品约束。

- 题目先给与情境对应的大图，老师用短句读题；选项用可辨认的图片。人物选项展示固定造型，场景中明确谁在说、谁在听、谈到谁，不能让孩子先读姓名。
- 操作以点图、拖拽、配对、示范模仿为主，一屏一个任务。按钮有明确图形与至少 48px 的触摸区域。提供可重播语音和音频失败后的重试。
- 文字用于辅助与识字目标本身；允许放大目标汉字，但不能用满屏字卡代替情境，也不能把文字选项配上装饰图就算完成适龄设计。
- 读题与反馈复用项目老师的预生成语音，不使用浏览器或系统机械音作为替代。
- 提示逐级增加，演示只在请求帮助后出现。作答前所有选项待遇一致，不通过颜色、位置标记或图片高亮泄露答案。
- 图片支持的理解任务不等于独立识字测验；学习记录必须明确能力证据的范围。

验收时遮住非目标文字：孩子听题后是否能找到情境、区分图片选项、选择、理解反馈并继续？再核对人物造型一致性、语音内容与图片一致性、小屏布局和恢复进度。

落实位置：根目录及 Student Web、OpenMAIC 的 AGENTS；`backend/content/low_reading_policy.v1.json`；`textbook_pedagogy.py` 的一、二年级教学约束。已有发布课程仍需逐课审核，更新规则不代表历史课件已全部改造。
