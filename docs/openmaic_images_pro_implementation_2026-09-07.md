# OpenMAIC 图片与 Pro 制作入口实施记录

本记录接续同日官方差距审计。MAIC-UI 暂不集成；本轮实现 Qwen 图片生成及原生 Pro 制作入口，不代表官网全部功能和展示质量已验收。

## 制作入口与项目结合

- 本机制作入口：`http://127.0.0.1:3100/workspace`。
- 选择自己的课程后编辑：`/workspace?course=<stageId>`；对话与课程并排：`/workspace?session=<sessionId>&course=<stageId>`。
- 启用官方 Pro、编辑器、PPTX 导入与导出入口；视频导出仍需实际 Render Service。
- 制作端使用服务端 DocumentStore 和原有匿名 owner cookie 保存；学生端保持原有存储及 gateway 授权。没有把服务端 token 交给浏览器，也没有启用全局 persistence。
- 工作台用于制作和修订草稿。现有自动生成并发布的课程属于不同的正式任务 owner，不会自动进入作者列表。本轮未实现“复制正式课为草稿、审核后重新发布版本”的桥接，也不会直接覆盖孩子正在学习的课。

## Qwen 图片链路

复用现有服务端 DashScope API key，启用 `qwen-image / qwen-image-max`。密钥保留在服务端。新正式目标使用版本化图片策略，允许 Agent 在教学需要时生成图片；不是强制每页或每课生成图片。

生成工具、持久化来源事件、同课堂文件、SHA256、真实图片格式及尺寸、页面引用和媒体回执贯通；后端在候选、发布与学生启动阶段复验回执和媒体可读性。0 张图片可以合格，但启用新策略的任务必须有媒体回执。

旧任务继续使用保存的无图片策略及原始请求摘要、目标指纹和回执格式。只接受精确旧目标或精确新目标，其他漂移继续拒绝。

真实服务调用已成功生成并保存一张 1024×1024 PNG（1,245,178 字节），SHA256 `df5d634d9c86de9a248fc3704e667682a1c722024d814d63b50e65cd8e7b840a`。这是技术连通性样本，未发布为课程：提示要求 3 个苹果，视觉检查实际为 4 个，说明生图不能替代教学内容审核。

新创作提示明确要求：插图用于辅助说明和情境；精确数量、文字、公式、几何关系及答案依据使用可校验的课件元素或 HTML，不以生成图片作为唯一答题依据。本轮没有增加多模态事实审核，不能把文件校验称为视觉教学审核。

## 视频用途

视频生成用于课件内的短演示素材，例如植物生长、动物动作、生活情境。参数可调、拖拽、实验等互动由 HTML/3D 承担；整节课导出 MP4 是另一条渲染流程。视频 provider 尚未配置，本轮没有开启视频生成或批量重新生成课程。
