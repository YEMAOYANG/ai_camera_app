# 家长注册到学生课堂：本机自测

当前本机正式开放小学一年级。其他年级可保存档案，但尚未开放正式课程。

## 入口

- 家长 App：已经启动的 iPhone 模拟器；或本机浏览器打开 [家长端](http://127.0.0.1:5188)。
- 学生网页：同一局域网打开 [学生端](http://192.168.228.95:3000)。
- 手机与电脑使用同一 Wi-Fi。学生网页统一使用上面的局域网地址，避免在不同域名之间切换导致需要重新配对。

## 从新账号开始

1. 家长 App 选择“登录或创建家庭”，输入手机号并获取验证码。本地开发环境会自动填入开发验证码，不发送真实短信。
2. 选择家长身份，填写孩子昵称，选择“小学 · 一年级”，完成设置。
3. 系统自动创建年级课程准备计划。同年级、同版本的已验证课件会立即共享给新孩子，其余课程由后台逐门生成；不需要等待整批 30 门。
4. 学生网页打开登录页。家长 App 可扫码授权；也可从“我的 → 孩子资料 → 学生学习空间”设置 4 位学习 PIN，创建配对码。
5. 学生网页展开“无法扫码？使用配对码”，输入家长 App 的 8 位配对码。配对码 10 分钟有效、只能使用一次。
6. 在“今日学习”点击已就绪课程的“开始这节课”，再点击课堂里的“开始上课”，允许浏览器播放老师声音。
7. 按课堂顺序学习，提交每道练习，并听完最后一页的讲解。返回学生端“我的学习”，确认该课程显示“已完成”；仅翻到最后一页或提交完练习，不等于课程完成记录已同步。
8. 回到**同一家庭账号**的家长 App，打开“首页”，下拉刷新。在“今日学习”找到这节显示“已完成”的课程，点击“查看学习报告”，查看“最近一次学习报告”中的答题结果、本次总结和下一步建议。学习报告入口在这张课程卡上。

如果家长端仍显示“学习中”，先确认学生端最后一页已经播放完成，再下拉刷新家长首页。如果弹窗显示“报告还在生成”，稍后重新打开“查看学习报告”。

后续使用同一浏览器时用学习 PIN 解锁。课堂会保存学习进度。课程尚未完成制作时会显示准备状态，不能把“制作中”当成可开课。

## 本机服务

从项目根目录检查或恢复后端、学生网页、课堂服务和课程 worker：

```sh
./openmaic-runtime/scripts/local-test-stack.sh status
./openmaic-runtime/scripts/local-test-stack.sh start
```

家长 Flutter Web 是单独进程。关闭后可从 `mobile/` 启动：

```sh
flutter run -d web-server --web-hostname 127.0.0.1 --web-port 5188
```

电脑 IP 改变时，需要同步修改家长 App、Student Web 与课堂的本地地址配置。此说明面向当前本机开发环境，不代表所有年级或公网生产部署已经完成。
