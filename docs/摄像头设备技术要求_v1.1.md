# 摄像头设备技术要求

> 用于厂商选型、工程样机确认和定制报价。设备必须能脱离厂家 App 和厂家云使用。

| 模块 | 最低要求 |
|---|---|
| 视频 | 2K/3K 以上，H.264/H.265，主辅双码流，低照度/夜视，约 110–120° 广角。 |
| ONVIF | 必须开放；兼容 Profile S，优先 Profile T；支持 WS-Discovery、设备信息、Media、码流地址、截图、PTZ、预置位和运动/人形事件；提供账号鉴权方式及测试报告。 |
| 实时视频接口 | RTSP 必须开放，WebRTC 可选；支持实时流、截图和事件短片，不能只能通过厂家 App 观看。 |
| 云台 | 水平 360°、垂直至少 90°、低噪音；开放方向、停止、回中、预置位和限位控制。 |
| 麦克风 | 双麦或四麦，支持 16 kHz/48 kHz、3–5 米拾音；可持续输出音频流。 |
| 音频处理 | 支持 VAD、AEC 回声消除、降噪，最好有 AGC；播放语音时不得反复识别自身声音。 |
| 扬声器 | 2–3 W 以上；支持 PCM、Opus、AAC、MP3 或 WAV 中至少两种，最好支持实时音频流。 |
| 播放控制 | 必须开放播放、停止、打断、队列、音量、状态和错误码接口；不能只能播放固定报警音。 |
| 本地唤醒 | 支持离线唤醒词，可定制 2–4 字名称；待机时不持续上传环境音频。 |
| 基础端侧 AI | 支持人形、运动、虚拟区域、基础声音事件；最好支持坐姿初判和离线任务提醒，端侧模型可升级。 |
| 配网与绑定 | 2.4G/5G Wi-Fi、BLE 配网、二维码绑定、局域网发现、换网和断网自动重连。 |
| SDK/API | 提供 Linux ARM64 SDK，或完整局域网 HTTP/CGI、MQTT、WebSocket 接口；须含文档、头文件/库、Demo、错误码和版本兼容说明。 |
| 私有服务器 | 可连接我方 MQTT over TLS、WebSocket 或 HTTPS 服务，支持心跳、事件上报、远程命令和断线重连；不得强制依赖厂家云/P2P。 |
| 设备管理 | 唯一设备 ID、序列号、硬件/固件版本、在线状态、日志、重启、恢复出厂、解绑和二手重置接口。 |
| 存储 | 建议 32 GB eMMC，可选 TF 卡；可保存事件截图、短片、模型、日志和断网任务队列。 |
| 隐私 | 物理遮挡或明显电子隐私盖；查看、录音、通话和隐私模式有明确灯效；隐私模式下停止采集和上传。 |
| 安全 | 每台设备使用独立凭证/证书，TLS 1.2 以上，接口鉴权和权限控制；禁止通用默认密码、未授权调试口和直接暴露公网。 |
| OTA | 固件签名校验、升级进度、设备回执、失败回滚、灰度发布和远程诊断；升级后不得破坏 ONVIF、RTSP、音频和 PTZ 接口。 |
| 可靠性 | 支持 7×24 小时运行、断电/断网自动恢复、异常进程自恢复；满负载连续运行 72 小时无异常重启或危险温升。 |
| 厂商交付 | 2–3 台同硬件/同固件工程样机，完整规格书，ONVIF/RTSP 资料，SDK/API 与 Demo，固件升级包，商用授权、定制费、MOQ 和交付周期。 |

**说明：** ONVIF/RTSP 不能替代扬声器、音频打断、隐私、配网和 OTA 接口；这些能力必须通过开放 SDK 或局域网 API 验证。
