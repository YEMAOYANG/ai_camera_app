## 缺陷、修复和验证

1. **模型思考配置丢失。** Next 编译后存在多个思考上下文模块实例，后加载的实例替换全局载体，导致较早调用者写入的禁用配置无法被 Provider 读取；动作生成也缺少强制阶段配置。实际 HTTP 请求与返回 reasoning 用量证实问题。修复后复用同一全局异步上下文载体，并把 scene-actions 加入强制策略。真实 SDK 加 mock 网络的生产编译验证覆盖 13 次请求、其中 11 次并发，全部符合策略，不发生 Provider 调用。
2. **讲解的高亮指向不一致。** 草稿的十个蓝点和三个黄点数量正确，但“一个十”的高亮指向单个黄点。动作生成原先只能看到“shape element”，缺少颜色、边界和分组信息，未发现确定性的 ID 重映射错误。修复为保留真实元素 ID，并传递颜色、形状、位置、区域包含关系和元素数量，区分整组与单个图形。新增用例使用真实 21 元素草稿，未手工改写付费结果来充当通过证据。

独立教学检查同时升级为 `mira.formal-course-review.v1.1`，检查讲解与高亮实际目标的对应关系；旧检查缓存不能冒充新版本通过，原审查预算也不会因升级重置。
