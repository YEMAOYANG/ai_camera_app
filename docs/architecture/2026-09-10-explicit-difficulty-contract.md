# 显式课程难度合同（2026-09-10）

二至六年级的正式课程把 `difficultyCode`（`basic / standard / challenge`）同时绑定到授权的 `courseTargets`、持久化 `content_json`、Host 回执与语义指纹、题目生产请求的 `objectivePolicy`，以及课件 `teachingBrief.course` 与 `teachingBrief.difficultyPolicy`。课件生成再转发为 `generation.difficultyPolicy`。档位来自版本化槽位清单；消费者不得根据 `variantOrdinal` 的大小推算难度。当前每知识点明确分配标准、基础、挑战各一槽，每年级仍为 27 槽，不增加自动生产授权。

一年级原有内容合同、校验数据摘要、语义指纹、回执字段不变。高年级使用 `formal_curriculum_authority.v2.json` 与跨语言 `formal_objective_policies.v2.json`；各年级独立封印，135 个规则条目包含完整的档位及可判分约束。生产请求和恢复重放都携带同一档位，候选课件不允许自行改档。

语文二年级按事件顺序取信息，三年级处理多次通知修订，四年级推演条件链，五年级追溯因果链，六年级综合多份资料或用明确反例判断观点。英语三年级按事件先后理解阅读，五年级追溯英文因果信息，六年级处理跨资料共同条件与时态对比。综合资料题要求每份资料都对唯一答案有贡献，拒绝用无关句子堆出长度。词法、句法及单步几何等知识点，基础直接求解、标准比较两项说法、挑战诊断三项说法；每项均独立验算，并要求正确与错误说法同时存在。

数学计算档位直接检查进退位、运算种类、精度和步骤。六年级百分数基础档做分数转百分数，标准档从总人数与分数同时求人数和百分数，挑战档处理先降价再涨价的基数变化。各档题例不能被其它档的校验器接受。变换人名、情境或数字不会自动改变难度。

个人选课使用已存的掌握状态和独立题首次作答证据，提示较多或需要练习选基础；已掌握、累计独立首次答对至少两题且无提示才选挑战，其余标准。缺档只回到本人完成过且仍正式可用的课复习，练习缺档返回书架。读取学习状态、选课和练习不会生产课程。

验证为纯确定性检查：135 个公开题例及跨档拒绝、135 个 Python/Node canonical 请求一致、六年级标准档候选课构造和 checkpoint/teachingBrief 一致、二/六年级 Host 回执验证与重放、原一年级冻结回执与指纹。没有模型调用、worker 启动或业务库写入。真实教学效果和整本教材覆盖仍需教研验收；本合同覆盖已注册知识点中的有限客观题，开放作文、主观赏析、发音评分等继续关闭。此文档不表示高年级已有正式发布课程。
