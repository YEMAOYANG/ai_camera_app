真实复核全部 49 个已有音频的 ASR 识别，最低相似度 9000/10000，阈值 8500。完整识别回执与音频摘要保存在 `output/textbook-publication-20260924/audio-audit/`。不确定的付费请求不会自动重发。

## 学生交付接口

1. `POST /api/v2/student/learning/textbooks/courses/<contentKey>/launch`：校验学生、年级、家长所选教材、发布内容摘要；复用每个孩子的独立任务与会话，签发 90 秒启动票据。
2. 学生 BFF 验证目标网关地址，iframe 打开 `/mira/textbook-launch`；网关交换票据并设置 HttpOnly 的课堂范围凭证。
3. `/internal/learning/textbooks/runtime/*` 只接受现有内部认证；每次重新核验学生会话、设备、教材选择与作品版本。4 小时播放凭证撤销登录后失效。
4. 原生 OpenMAIC 播放冻结课件和合成语音；网关只允许该课堂、清单内媒体和必要静态资源，校验素材字节摘要。互动 HTML 的图片与音频在认证后的课件响应中按审核清单内嵌，保持 opaque-origin iframe 隔离，避免 SameSite Cookie 使素材失效；不开放匿名媒体接口。实时讨论、提问、合成语音和语音识别保留 OpenMAIC 原功能；课件生成、编辑、导出和设置仍属于运营端。
5. `/mira/textbook-quiz` 后端判题，学生 JSON 不含答案与解析；每个孩子首次提交的练习结果幂等保存。报告仅描述选择题表现，不冒充口头朗读或书写掌握度。全部页面讲解结束并完成练习后才完成学习任务。

原生播放器补丁 `0127-mira-fixed-textbook-publication.patch` 已登记到 `upstream.lock.json`。其中误加的实时输入限制由 0129 撤回：固定教材约束的是共享课件内容，不是课堂交互。
