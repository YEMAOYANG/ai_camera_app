# 学生端书包动效第二版：制作与验收记录

日期：2026-09-24。状态：已实现并在本地生产构建验收。下文保留前期方案依据，实际实现以本节为准。

后续的 Radix 控件、放大构图与刷新目录后合书归位修复，见 [学生端控件与书包比例精修](2026-09-24-student-ui-refinement.md)。后续记录优先于本页的首版时长与验证数字。

## 已完成的版本

- 解锁、配对页使用同一个关闭的三维书包。真实 PIN 解锁、配对码确认或二维码交换成功后，才触发开盖、三本课本依次飞入、连续落位到首页。
- 首页保留语文、数学、英语三个入口。可直接点三维课本，也可以点下方的大文字按钮；可用性、教材版本、修订号仍来自原教材 API 和家长确认结果。
- 选择可用课本时，课本离开袋口、转向学生、绕书脊打开，再交接到真实教材目录。“回到书包”播放合书归位。首页静止时不持续渲染。
- 支持跳过动画、关闭动效、系统减少动态效果设置；资源加载失败、图形上下文丢失或切到后台时，导航仍可完成。播放期间避免重复点击，完成后恢复页面焦点。
- 语文仍进入既有共享教材课程库；数学、英语尚未就绪时明确显示“准备中”，不会生成课程或显示伪造内容。

### 原创素材与控制方式

本机未使用 Blender。此次用可重复运行的 Three.js 几何制作脚本导出原创 GLB，包含可开合袋盖、内腔、扣件、口袋、缝线、提手，以及三本科目课本的独立封面、书脊、书页。提手随袋盖运动，避免穿插；课本进入袋口时由真实袋身几何遮挡。

- 资产源：`student-web/scripts/build-schoolbag-model.mjs`，在 Student Web 中运行 `npm run assets:schoolbag` 可重新导出。
- 资产：`student-web/public/models/schoolbag/schoolbag-v2.glb`，1,935,324 字节，55 个网格，55,882 个顶点；统计在同目录 `asset-manifest.json`。
- 原创通用科目封面由运行时 Canvas 绘制，不使用出版社封面或教材内页图片。真实教材名称与目录在 DOM 页面中展示。
- 动画由 `motion-timeline.ts` 和 `schoolbag-renderer.ts` 控制，没有将动画片段烘焙进 GLB，也没有使用预渲染视频或外部付费服务。
- 当前时间线：装书 2,450 毫秒、取书展开 1,650 毫秒、合书返回 1,350 毫秒，正常路由落位另有约 430 毫秒交接。最终耗时还受页面加载影响；均可跳过。
- `SchoolbagMotionProvider` 在路由之间保留同一场景；低能力环境使用图标及正常科目按钮。移动端展开双页会根据宽高比调整镜头。

## 目标与当前问题

用户期望：解锁或配对页显示关闭的书包，真实认证成功后打开，教材飞入书包，连续转场到首页；首页选择科目时，从同一个书包取出对应课本并展开进入教材目录。

改造前的实现：认证页使用静态 `backpack-v1.png`；首页用同一张图片的前后两层形成遮挡，书本通过 CSS 平移、缩放和淡出后导航。图片无法表现袋盖的真实开合，选中对象与目录页之间也缺少连续的空间关系。现在这两处已替换为上述共享三维场景。

保留现有教材版本、家长确认、共享课程库及真实课程可用状态。动画展示不改变教学内容或课程生成逻辑。

## 推荐的视觉方向

温暖的微缩三维场景：奶油白背景、织物书包、圆润书角、纸张厚度、柔和接触阴影。让材质、灯光、物体运动和镜头保持一致。

镜头只做小幅推近和构图移动，不采用绕场旋转。主要表现书包袋盖的铰接运动、课本进入袋口的遮挡、书本由侧面对齐正面的转动、封面绕书脊展开。首页静止时不持续漂浮。

## 前期动作分镜

以下时间是制作起点，需用实机原型调整，不是已测量的性能结果。

| 阶段 | 建议时间 | 画面与行为 |
| --- | --- | --- |
| 等待解锁或配对 | 静止 | 关闭的书包放在桌面；保留正常输入、扫码、错误反馈 |
| 认证成功 | 0–0.45 秒 | 确认成功后袋扣松开，袋盖向后掀开；开始收起表单 |
| 装入教材 | 0.45–1.55 秒 | 语数英课本沿各自短弧线依次进入，间隔约 0.1 秒；袋口正确遮挡课本下部 |
| 落位与过渡 | 1.55–2.1 秒 | 书本落位，书脊和科目仍可见；镜头移动到首页构图，导航出现 |
| 首页待选 | 静止 | 三个科目有明确的大点击区域；课程未就绪时显示真实状态 |
| 点击可用科目 | 0–0.3 秒 | 对应课本轻抬，其他课本保持原位 |
| 取出课本 | 0.3–0.75 秒 | 课本离开袋口、移至中心，封面转向学生；阴影随距离变化 |
| 展开目录 | 0.75–1.15 秒 | 封面绕书脊展开，书页表面与真实目录页面对齐，交接键盘焦点 |
| 返回首页 | 约 0.7 秒 | 课本合上、回到原位，保留刚才的科目与目录进度 |

前期设想区分首次配对与日常解锁的入场时长。本次实现先共用完整装书动作，实际时长见上文；提供跳过/减少动效入口，减少动态效果设置下直接展示结果。素材失败时使用图标与正常科目按钮完成同样的业务流程。

## 工具选择

| 路线 | 适合承担的工作 | 对本项目的判断 |
| --- | --- | --- |
| Blender + GLB + Three.js | 制作可开合书包、教材模型与动画片段；前端按状态控制播放 | 推荐作为正式产品路线。资产可由项目托管，真实三维遮挡与选科交互可以共用场景；需要建模、动画和设备性能验证 |
| Spline | 可视化制作三维场景、时间线、事件与原型 | 适合快速审片与互动打样。正式接入前核对导出能力和套餐；当前完整自托管 ZIP 属于企业套餐 |
| Rive | 插画风书包、分层变形、输入驱动的交互动画 | 如果选择绘本式二维风格，这是合适的替代路线；不是当前织物三维质感的直接替代资产 |
| Runway 图生视频 | 从风格图试镜头、节奏与固定短片 | 可做动效预演。视频不能直接提供可独立控制的袋盖、书本和任意选科状态；正式使用需要额外的分支片段和页面衔接 |

推荐是基于本项目需要自由选科、返回与连续转场的工程判断。外部工具能帮助制作，最终质量仍取决于模型拆件、材质、动画和界面衔接，不能仅靠替换一个动画库保证。

## 需要制作的资产

1. 一个原创书包：主体、袋盖、袋口内衬、扣件可分别控制；关闭与打开使用同一模型，包含真实内腔和合理的旋转支点。
2. 一个可替换封面的课本模型，复用于语文、数学、英语：封面、书脊、书页分别建模。标题由项目的真实教材数据驱动。
3. 动画片段：开包、装书、取书、翻开、合书、归位；物体运动与镜头运动分别可控。
4. 统一的材质、低成本灯光/阴影方案，以及同场景导出的静态后备图。
5. 可选的短促装书与翻页音效，尊重静音设置；音效不能成为认证或导航成功的条件。

不需要为每个学生或每本教材重新生成视频。复用模型和动作，更换教材标题/封面及可用状态即可。现有原创书包图片可作为造型参考，但不是三维源文件。

## 接入边界

这是学生 Web 的表现层改造，当前判断无需数据库结构或教材 API 变化。

认证服务确认成功后，页面触发动画事件，始终以真实认证和教材访问结果为准；登录失败保持书包关闭并允许重试。动画结束、跳过或失败都必须能进入正确的已授权页面，不能让动画资源阻断学习。

拟增加一个共享书包场景和统一的转场控制层，覆盖解锁、配对、首页及进入教材目录的交接。需要设计 Next.js 路由切换期间的场景持久化，避免动画结束前场景被卸载。具体集成点在实施时按当前路由结构确认。

候选修改位置：

- `student-web/src/features/auth/learning-path-preview.tsx`
- `student-web/src/features/auth/unlock-form.tsx`
- `student-web/src/features/auth/pairing-form.tsx`
- `student-web/src/features/auth/qr-pairing.tsx`
- `student-web/src/features/learning/learning-schoolbag.tsx`
- `student-web/src/components/student/schoolbag-shell.tsx`
- 新增共享三维场景、转场控制组件与原创模型资产目录

验收先做一条真实链路：关闭书包 → 认证成功 → 装入 → 首页 → 选择语文 → 展开目录。重点看遮挡、动画首尾姿态、触屏点击、返回、减少动态效果、资源失败和低端设备表现。播放期间之外暂停不必要的渲染。保持 DOM 中可访问的科目按钮，不能让 Canvas 成为唯一的操作入口。
