# 小学课程供应与深度交互升级

日期：2026-09-10。按用户最新要求，本轮完成二到六年级代码流程，不创建课程，不扩大验证范围。现有三门课保留，未调用收费模型或启动课程生产 worker。

## 实现范围

- 新课默认采用版本化适龄深度交互，要求核心目标对应示范、真实操作、理由反馈和独立判断。服务端绑定最终课件及双视口浏览器证据，教师脚本和 QA 操作不计作孩子已学。
- 一至六年级的注册知识边界、内容生成检查点、客观题验证、候选课件、发布与共享补库按年级隔离。一年级旧合同保留；二至六年级只覆盖明确注册的客观题试点，不表示完整教材/全年课程已备齐。
- 共享课程读取不发起生成。显式开放范围决定补库上限；多个年级公平轮转、逐项检查 lease 与当前授权范围；升级政策后仍复用兼容旧课，避免重复制作现有三科首课。
- 个人学习状态区分可学、暂无课程、待准备、暂停、范围已完成和不支持的年级。至少一门可学课程时隐藏备课百分比并停止备课轮询；回到页面静默刷新。掌握记录按年级、学科和知识点隔离。
- 独立复习题库从孩子已完成、仍符合正式可学门禁的课件投影，保留原课版本与答案合同；抽题与评分不调用模型。已开始课堂和练习均使用冻结题目。
- 新版费用账按生产、必要实时教学和额外互动分开。生产整课各阶段共用同一预算授权，重试不能另开预算；实际供应商调用前预留、一次派发、按真实 usage 结算；不明确的结果保留占额。
- 必要教学对话由服务端保存，重试与恢复读取原记录，孩子续答仍绑定原课程。场景完成校验该场景全部冻结讨论，整课完成再次校验全课讨论；生成了语音不等于已经播放或听到。
- 二到六年级学习空间已开放。未生成课程时明确返回 `empty` 并显示“暂无课程”，不代表年级关闭；读取状态不会建立生产 owner，也不会显示虚假的生成等待或备课百分比。`not_open` 仅保留给不支持的年级。

## 启用边界

预算政策默认关闭且没有真实额度授权。高年级生产范围默认空；不因用户注册或此次升级自动产生费用。正式发布新内容必须具备显式范围、费用授权、Host 验证、媒体与教学验收。旧课程不自动升级为新交互合同。

是否达到用户提供的官方示例，最终以新生成课件的实际操作和学习过程判断；此次代码和无付费验证不替代新课效果验收。
