用户追加的官方课程参考已实际操作，详见 [官方课件交互参考](2026-09-10-official-courseware-reference.md)。

## 结论

共享预生成完整课程、按学情选课、按知识点补库的总体方向成立。需要补齐默认交互设计、学习操作证据、内容撤回/范围结束状态和旧文档冲突。深度交互可以作为新课默认能力，但必须落实到正式 Pro 生产合同和最终课件验收；只改官方首页开关不会改变本项目正式课库生产。

## 官方“深度交互”是什么

它偏向生成能让学生动手探索的学习页面：改变模拟参数、操作小游戏、展开图解、观察三维结构或运行适当代码。教师可以通过界面操作提示和示范，引导学生观察变化。[官方功能说明](https://github.com/THU-MAIC/OpenMAIC#deep-interactive-mode-new)

它属于课程创作和课件交互能力。实时讨论、自由问答、语音输入是其他调用路径；启用深度交互不等于自动开启无限多角色对话，也不意味着每次拖滑块都需要模型。

官方开关所在的经典首页把 `requirements.interactiveMode` 传入大纲生成，选择互动优先提示。Pro 还有 `deep-interactive` skill，其固定版本的约束文件包含至少 60% interactive、开场 slide 和相邻互动形式不重复等规则。该通用 skill 的约束检查是诊断机制，不能假定本项目选用支持技能后已自动执行了所有发布门槛。

## 现有项目的实际状态

| 层次 | 核对结果 |
| --- | --- |
| 经典首页 | `app/page.tsx` 默认 `interactiveMode=false`；只影响从该首页启动的标准创作 |
| 正式课程入口 | `classroom-generation.ts` 的正式合同分支直接进入 `generateMiraFormalProfessionalClassroom`，不经过该首页和普通大纲开关 |
| 技能 | TS/Python 基础技能均包括 deep-interactive；有真实读取与逐页上下文回执 |
| 提示规则 | 正式场景上下文选取交互类型与知识观察章节，并明确不强制 60% 页面占比或类型轮换 |
| 当前发布要求 | 至少包含讲解、测评和互动；互动页面检查 HTML、脚本、控件、配置及双视口操作探针；未建立逐核心目标教学操作链的独立完整合同 |

## 默认方式建议

推荐新课默认采用**适龄深度交互**：每个核心目标映射到老师示范、学生有效操作、可观察结果、理由反馈及独立判断。可用一条学习链覆盖相关目标；阅读材料和必要讲解保留合适形式。数学用参数/数量/结构操作，语言课用分类、排序、证据选择或语义关系，不为凑比例强上 3D、编程或小游戏。

官方完整结构可以作为独立对照配置，但不能把适龄策略声称为与官方所有规则完全一致。这一推荐需在新内容合同中明确，不能靠工作人员口头判断每门课是否“互动够多”。

未来实施要改的真实边界：

1. 新版 `interactionDesignPolicy` 进入后端和 Runtime 对应策略注册、正式生成输入及目标指纹；默认启用的新任务与旧合同分开。
2. Pro 规划和逐页制作使用该政策；最终校验检查目标与教学链的映射，拒绝只有装饰按钮或没有反馈的页面。
3. 页面检查实际操作目标控件，验证结果与教学内容一致，并覆盖错误、重试、复位和触屏路径。
4. 完成事件区分老师示范、孩子操作、独立测评；固定场景版本和操作 ID，避免自动播放直接计完成。
5. 后端发布校验同一冻结快照的策略、操作验证和质量回执。改变现有网页默认值或仅补 `interactiveMode=true` 不满足这些条件。

无模型验证先证明新旧合同兼容、未来任务默认选中新政策、假交互被拒绝及旧任务可恢复；之后再在明确的付费批次内生成代表性样课，实际验证效果。当前三个课件不会因默认政策调整而自动升级。

## 本次发现的其他关键缺口

- **撤回要连回补库。** 被撤回或媒体失效的课不再计入库存，按范围补充新版本；不能只做撤回按钮而下一课永久断供。
- **学完开放范围要有终态。** 显示单元完成和下一范围状态，复习明确标注；没有生产任务时不显示“正在备课”。
- **旧资料与当前方案冲突。** 早期文档包含 Kimi、固定课件、按孩子缺课触发、每日两课等历史表述；本次加注边界，并让 README 的当日课数描述服从服务端实际分配。三科学科覆盖不能直接推出每天必学三门。
- **内容质量不只靠代码。** 新年级规则和新题型需要教研审查，稳定范围再逐步自动化；不能承诺任意题型都能零人工可靠评分。
- **费用和容量仍需实施验证。** 存在回合上限不等于全站日费用保护，控制生成并发也不能保证实时问答容量。现有内容共享可降低重复生产，但没有测量前不报每人固定人民币成本。
