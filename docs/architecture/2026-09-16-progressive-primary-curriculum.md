# Mira 一至六年级分级课程与连续学习规则

日期：2026-09-16。课程版本：`mira.primary.progressive.v1`。

## 分级是第一层边界

每个年级有自己的语文、数学、英语课程顺序，按“年级 → 学科 → 单元 → 课次”从该年级的基础内容逐步加深。不能将一至六年级串成一条所有孩子都从头重学的路线。

此规则覆盖一至六年级的全部三科，由统一逻辑读取各自年级的独立目录，不为六年级单独写特殊分支。当前自建目录各年级的起始单元如下，每个单元内部再从入门课次逐步加深：

| 年级 | 语文起始单元 | 数学起始单元 | 英语起始单元 |
| --- | --- | --- | --- |
| 一年级 | 听音与单韵母 | 逐物数数 1～5 | A–E |
| 二年级 | 部件与构词 | 100 以内进位加法 | CVC 与编码 |
| 三年级 | 准确词义 | 两位数乘一位数 | 词尾 e |
| 四年级 | 段落组织 | 更大的整数 | 更多拼读模式 |
| 五年级 | 表达目的 | 小数乘法 | 过去时间与 was/were |
| 六年级 | 观点事实证据 | 分数乘法 | 指代连贯 |

`basic` 表示本年级本课的入门难度，不表示所有年级都退回小学一年级零起点。

孩子的所选年级确定入学基础：没有低年级历史记录，不代表低年级知识都不会。系统不会为此生成虚假低年级掌握记录，也不会自动列出低年级必修或摸底清单。针对具体缺口的补课需要另有明确依据与范围，当前默认流程不推送跨级补课。

## 注册目录与生成内容

- 权威数据：[progressive_curriculum.v1.json](../../backend/content/progressive_curriculum.v1.json)。
- 注册器：[progressive_curriculum.py](../../backend/content/progressive_curriculum.py)。
- 编排来源：[语文与英语](../curriculum/primary-language-sequence-v1.md)、[数学](../curriculum/primary-math-sequence-v1.md)。

目录包含 187 个单元、1038 个细课次，覆盖一至六年级三科上下阶段。这是 Mira 自建课程目录，不是已生成的 1038 份课件，也不表示与某版教材逐页一致。

每课固定课次、年级、学科、单元、先修关系、学习目标、内容限制与验收方式。旧 55 个大能力边界保留历史用途，不映射成所有细课次已掌握。

新课生成必须绑定本年级登记的 `lessonId`，从该课的 `basic` 内容开始。AI 可制作例子、故事、游戏与 3D 互动，不能更换年级、课次或本课教学目标。结构化 Prompt 和独立审核都要求实际文本符合年级、单元与目标；低年级先修只能必要时简短回顾，不能替代高年级的主课和练习。

## 个人学习顺序

`ProgressiveLearningService.get_path()` 默认只返回孩子当前年级的课程；推荐是本年级按顺序的下一课。同年级内，所需前置课次没有掌握时，后续课次仍然锁定。过去已有的低年级进度留作历史，不因缺失而阻塞整个当前年级。

完成课堂与掌握知识分开保存。客观课使用服务器确认的独立首答证据，遵循该课登记的题数与准确率标准，当前最低为五道不同题、至少两组、正确率八成。提示、重复作答、只改编号或排序的题不能制造新的独立证据；延后复习单独确认稳定掌握。

朗读、书写或表达等观察课，完成实际课堂后由家长按课程冻结的表现要求确认；学生不能调用家长确认接口，选择题不能代替实际表现。

新分配、日常推荐和直接新开课均受当前年级限制。查看其他年级只是目录预览，不修改孩子年级，也不能从预览开启其他年级课堂。历史已经开始的课堂保留原课程、包与 Runtime 身份，可以恢复；恢复权限不能授权新开一节跨级课程。

## 日常备课与正式发布

日常供给只登记当前孩子、本年级、当前课次的缺口。缺六年级课程就等待六年级课程准备，不能拿一年级拼音或其他年级课程补位。每批有两组基础练习，已用完但尚未掌握时可补新批次；按真实批次和套题槽位定位缺口，避免把已用的第二套反复当成待补课。

完整目录仅用于稳定课程身份，不会因为注册了一至六年级课程而自动生成全部课件。只有明确启用的供给范围进入生产。

正式流程继续使用：内容生成与宿主验收 → OpenMAIC 专业课堂 → 教学和交互审核 → TTS 与 ASR → 媒体及会话能力核对 → 单课正式发布。单课可独立发布，不等待整年级课件全部完成；旧冻结任务仍按原合同恢复，不能重新标号充当新体系课件。

OpenMAIC 改动保存在 `openmaic-runtime/patches/0114-mira-progressive-primary-curriculum.patch` 及 `upstream.lock.json`。后台的年级教学边界同样传入课堂生成与审核。

## API 与界面

- `GET /api/v2/student/learning/path?subject=math`：按当前学生实际年级返回路线。可带 `gradeCode` 查看其他年级目录，但预览不可开课。
- `GET /api/v1/learning/path?childId=...&subject=chinese`：家长查看同家庭孩子路线。
- `POST /api/v1/learning/path/observations`：家长提交孩子、课次、服务器确认标识与实际观察结果。
- 课程、任务和会话入口沿用既有接口，新课次的 `progression` 标记为 `granularity: lesson`。

学生 `/learning/path` 默认只展示本年级单元和下一课，没有默认低年级补课或摸底入口。基础摸底底层记录及去重保护保留兼容用途，默认状态为 `not_required`，不接受无明确范围的新摸底，不能再次因历史记录为空而自动回到一年级。
