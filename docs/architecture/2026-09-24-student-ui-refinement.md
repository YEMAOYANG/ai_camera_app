# 学生端控件与书包比例精修

本轮范围：学生 Web 的解锁、配对、书包首页、教材目录，以及这些页面间的三维转场。教材 API、身份认证、家长确认版本和共享课程库的业务边界保持不变，无数据库迁移。

## 控件体系

沿用现有 Radix Slot + CVA 按钮基础，补充 Radix Select、Collapsible、Switch；PIN 使用 `input-otp`。这些库处理键盘、焦点和控件状态，项目自己维护 Mira 的颜色、尺寸、字重与边框，不套用外部默认主题。

- 四位 PIN 用一个真正的密码输入控件承接输入、粘贴和辅助技术，四个视觉格显示掩码。错误保留服务端提示并重新聚焦输入，成功后才开始装书。
- 单元选择器通过 Portal 显示选项，不被内容容器裁切；选择单元仍使用服务端目录中的标识。
- 家长说明、配对码展开使用统一折叠组件。配对码收起保留输入；展开时继续暂停二维码交换轮询。
- 动效偏好使用标准开关；遵守已有系统减少动态效果设置。
- 统一普通按钮、轻按钮、输入框、焦点、错误和禁用样式。儿童常用操作保持至少 48 像素触控区域，降低非主要文案的字号、字重和边框重量。

源文件：`student-web/src/components/ui/`、`student-web/src/styles/student-ui.css`、`student-web/src/styles/tokens.css`。

## 构图与动作

登录页改为左侧主场景、右侧简洁表单。桌面书包画布由 380×330 调整为随列宽变化、约 510 像素高；首页画布约 560 像素高。静止场景镜头强调系数为 1.3，移动端分别调整画布，避免单纯放大导致溢出。

全屏转场单独使用镜头比例，在落位到首页的 430 毫秒中逐渐交接至静止镜头，避免课本入包时被屏幕边缘裁切。

返回动作改为独立的 2,100 毫秒时间线：先合封面，再把课本移回袋口，最后落入原位。经过服务端确认的目录会预先准备对应科目的场景，因此刷新或直接打开目录后，点击“回到书包”、顶部首页或品牌入口也能播放正确的归位动作。图形失败或关闭动效时仍可直接返回。

源文件：`student-web/src/components/schoolbag/`、`student-web/src/features/learning/learning-textbooks.tsx`。
