# 《天地人》互动样板 v2

## 范围与架构

面向一年级初识字孩子，围绕天、地、人、你、我、他设计一节可独立体验的原创课程。沿用当前绘本插画和已核对配音；新增操作提示使用本机中文合成语音，无付费 Provider 调用。样板用于验收教学与交互，不改动已发布的 storybook-1、正式学生记录或整册权利审核。

文件边界：`backend/content/textbooks/samples/tiandiren-v2/` 保存版本化教学内容、网页和素材清单；`backend/services/textbook_sample_service.py` 负责确定性状态机和学习证据；`backend/scripts/serve_textbook_sample.py` 仅在本机提供样板；`backend/tests/test_textbook_sample.py` 验证证据与恢复。没有 Flutter、Next.js、网关或业务数据库结构变更。

服务端拥有题目答案、首次作答、提示记录、补练清单和复习时间。样板使用独立 SQLite 文件和匿名 HttpOnly 会话，不创建真实孩子或任务。正式接入时复用现有 `learning_sessions.runtime_state_json`、报告与 `tasks`，并发布新教学版本；不能将这里的匿名体验导入真实学习记录。

## 完整体验

1. 花园导入：孩子主动点天、地、人物，听字音与具体解释。
2. 找字探险：把字牌拖到图里，或直接点选对应区域，三个字贴逐个点亮。鼠标、触摸指针和键盘点选走同一服务端判定。错误不扣分、不倒计时；需要时先给方向提示，再示范。
3. 小小配音员：亲自换说话人，观察我和你跟着角色变化；固定六轮角色挑战防止只记衣服或位置。
4. 六字独立挑战：逐题确认，保留第一次作答；读题不算提示，教学提示及成人帮助单独记录。已会的孩子可直接从这里开始。
5. 针对性补练：仅为错误或获得帮助的目标安排图中操作，再进入六道不同情境的验证题。补练不会擦除第一次错误。
6. 完成与复习：显示本课证据与简短家长反馈；服务端在完成 24 小时后解锁另一组题。提前体验仅重用已经做过的生活情境，不泄露真正的次日题，也不会形成延迟复测证据。可以再玩探险和角色游戏，复玩不覆盖首次记录或推迟复习时间。

题面避免直接印出本题的目标汉字，减少照着题干匹配字形的捷径。读题配音不算提示；解释性提示、示范以及体验者主动标记的成人帮助不算独立证据。系统不能自动知道孩子身旁是否有人辅导。

不自动评价口头朗读、书写或长期掌握。不用播放结束、点击数、贴纸或停留时长替代学习结果。

## 本机接口

- `GET /api/session`：创建或恢复匿名样板会话，返回 revision、phase、当前活动、可执行操作、已观察的反馈和进度。未作答题目不含答案、解析、提示内容或未来题库。
- `POST /api/action`：`{requestId, revision, action, choice?}`。服务端严格校验当前活动、可选值和顺序；同 requestId 同请求返回原回执，冲突返回 409。支持开始、探索、选择、提示、成人帮助、继续、角色演示与复习。
- `GET /api/report`：只返回此匿名会话已经产生的证据。首次无提示答对、补练、迁移题和真正到期后的复习分开统计。
- `/assets/<id>`：仅返回内容清单中经 SHA-256 校验的素材。没有通用文件读取、目录浏览或外部 URL 代理。

退出、刷新、服务重启均从服务端进度恢复。请求未确认时前端禁止继续，恢复后取服务端状态，不乐观增加分数。样板进程只绑定 127.0.0.1，检查 Host / Origin；静态响应和 JSON 均不包含发布凭据。

## 验收重点

正确 / 错误 / 提示 / 成人帮助 / 重试 / 双击 / 网络中断 / 刷新恢复；角色切换后答案变化；补练不重写首次证据；次日门槛使用服务端时间；提前预览不冒充复习；手机与平板大触点、键盘、减少动效、音频失败可恢复。真实儿童的自主完成率、家长辅导分钟数与学习收益仍需家庭试用。
