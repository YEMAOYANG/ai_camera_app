# 摄像头与课件共同参与成长图谱

沿用 `/api/reports/daily`、`/api/reports/weekly` 和现有任务、摄像头观察、学习会话数据。无数据库迁移，无额外模型调用。评分规则在 `backend/content/report_growth_policy.v1.json` 版本管理，由 `report_growth_assessment.py` 执行；Flutter 只展示后端结果。

## API

新增 `report.skillMaps[]`，每项对应一个孩子：`childId`、`childName`、`policyVersion`、`scope`、`skills[]`。单孩子时 `report.skills` 同步该孩子的结果；多孩子时不再生成混合分数。

每项 skill 含 `key`、`label`、`score`（0–100 或 null）、`maxScore`、`status`、`sampleCount`、`level`、`detail`、`sources`、`evidence[]`。证据包含日期、来源、直接支持的分子／分母、记录引用和说明。null 是“待观察”，有证据的 0 分仍是有效记录。没有默认分、完成次数加分或跨维度奖励。

## 口径

- **自理表现／整理习惯／运动参与**：家长明确确认或否决的相应任务，以及家长手动记录的完成结果。分数表示已有结果中的完成比例。到时自动结束、待确认、错过和摄像头离线都不等于能力差，不生成分数。
- **摄像头**：读取 `camera_observation_events` 与 `behavior_signals`，按家庭、孩子、设备、场景绑定。观察和信号的置信度都须达到 0.72；置信度只决定是否采纳，不换算能力分。目前直接支持收纳完成信号 `cleanup_done`／`toys_put_away`。其他摄像头文字和提醒仍保留在报告观察区，不从文字猜测能力分。
- **去重与纠正**：同一任务的摄像头和家长结果只算一次，家长确认／否决优先。未关联任务的连续收纳完成观察按孩子、日期、场景归为一个样本，避免连续帧刷分。
- **独立作答**：首次练习中独立答对／实际题数。提示、家长帮助已在学习服务的独立作答判断中排除，不重复惩罚；不足完整前测时不根据未答题扣分。
- **情境理解**：新情境检验中每个已作答目标最近一次独立结果。引导游戏、演示、未作答目标不充当独立证据。旧记录仅在已有完整检验结果时兼容读取。
- **复习保持**：最近一轮间隔复习里，每个已作答目标的首次回答；补练后通过不能回填成复习首次就记住。尚无复习作答时显示待观察。
- **专注表现／主动开始**：现有数据缺少能支持这两项的直接过程测量，显示待观察；不拿答题正确或任务完成代替。

课件学习证据写入原有 `reportDays` JSON 快照，新增 `assessmentEvidence`。首次练习归原始日期，复习归实际复习日期；历史快照不会使用未来结果。所有日期范围按北京时间处理。统计在每个孩子内去重，不把两个孩子混成一个能力图。

分数是本期样本的表现比例，未建立常模，不宣称心理测量或长期能力等级。图片支持下的理解不代表独立识字、朗读或书写。页面保留雷达结构，缺证据的维度不画零分点，可切换孩子并展开评分依据。
