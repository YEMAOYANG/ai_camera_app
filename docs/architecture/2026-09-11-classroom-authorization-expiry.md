# 已发布课堂的授权过期修复

用户在 2026-09-11 打开已发布六年级数学课时，Student Web 创建学习会话和启动票据均成功，Gateway 换票却返回 `learning_budget_invalid_authorization_expiry`。

原因是本地 Backend 的 `LEARNING_BUDGET_POLICY_PATH` 仍指向前一天的单课测试策略。该策略的固定窗口在 2026-09-10 20:30 截止，而且只列出当时的生成任务及测试学生会话。换票时，新教学授权的到期时间被截到这个已过去的时刻，在日期校验处拒绝；即使只修改日期，新学生会话仍不属于那份临时许可。课程、正式语音和发布证明并未过期。

## 运行边界

`backend/content/learning_classroom_policy.json` 是已发布课堂的持续运行配置：必要教学沿用 DeepSeek 和 Qwen 的原模型、价格记录及计量方式，`aggregateLimitsEnabled=false`，没有固定测试截止日期或测试账号名单。生产模板保持关闭，普通课程 worker 仍停止；已批准的单课生产策略和旧调用记录保留，不将生产许可延期。

授权由已经通过登录、课程发布与学习会话校验的后端入口签发。必要教学的原授权可在合法会话继续访问时续期；同一授权身份、课程、价格、用量账本保持不变，已撤销授权不复活。内部模型计量接口不能自行创建或续期学生权限。

学生端与 Gateway 的 API 契约不变。此次只验证故障入口、跨日续期和原有学习证据的保留，不生成新课程或重跑整节课。
