# Fraction activity context parser repair

The `primary_6 / math / fraction_ratio_percentage / standard` public prompt is an example of the frozen two-step assessment: derive participant count from total × fraction, then derive its percentage. The first Host parser mistakenly treated the example activity name `阅读` as mathematical authority. Equivalent questions using 绘画、合唱、运动、手工 had correct operands and answers but were rejected by that implementation.

The repair captures a bounded Chinese activity label and requires the same label in both the given condition and the question. It does not accept added sentences, quantity assertions, conditional clauses, changed membership, or mismatched labels. Total people, numerator/denominator bounds, integer participant count, requested answer format, and two calculation steps remain unchanged. The allowed percentage denominator is also corrected to `1, 2, 5, 10`, enforcing the existing maximum of one decimal place; `6.25%` is rejected. One-grade frozen contracts and all curriculum/difficulty policy hashes remain unchanged. This is a parser implementation repair under the existing policy, not a new easier assessment band or a changed published policy.
