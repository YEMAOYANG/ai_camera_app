# 学生端固定教材课程库

学生端以提前制作的教材库为唯一课程入口。同一年级、教材版本、目录修订、课次和教学修订对应一份共享内容；学生身份只用于访问范围、学校进度、个人学习和答题记录，不参与课件生成键。

## 分发和制作

- 登录、解锁、首页、旧“今天”、旧课程页、旧学习路线和独立练习页统一进入 `/learning/textbooks`。导航只保留“教材”，旧自研数据不删除。
- 学生只读取教材目录与已发布课件。尚未制作或审核的课次显示“课程准备中”，没有点击生成按钮，也不会因登录、刷新、切换单元而创建生成任务。
- `learning_textbook_course_builds.content_key` 继续作为制作幂等键。制作和发布走受保护的运营流程；OpenMAIC 负责提前制作与课堂播放，学生入口不调用生成接口。
- 发布版本先按教材课次统一确定，再检查个人访问状态。不得因某个学生暂时不可访问而退回另一份旧课件。
- 个人任务、课堂会话和答题仍沿用现有表；共享课程不因增加学生而复制。教材选择继续由家长确认，并受年级和学期约束。

## 后端规则

正常运行默认 `LEARNING_TEXTBOOK_LIBRARY_ONLY=1`，前端隐藏与后端限制同时生效。

| 接口 | 教材库模式行为 |
| --- | --- |
| `GET /api/v2/student/learning/textbooks` | 返回当前年级真实入库的教材版本 |
| `GET /api/v2/student/learning/textbooks/{edition}/contents` | 返回固定目录、原创导学、已发布课件身份；只读 |
| 旧 `today`、`today/assign`、`library`、`path`、`placement`、`reports/latest`，独立 `student/practice` | 身份验证后返回 409 `student_textbook_library_required`；不调用旧业务服务 |
| 课程详情、开始、收藏；任务开课、会话播放和答题、OpenMAIC 启动 | 先核对已发布教材绑定、完整性摘要、家长选书及所属学生，再保留原发布、媒体、课堂和答题校验 |
| OpenMAIC 已签发票据兑换与运行会话恢复 | 再次核对教材绑定；旧自研课堂凭据不能重新进入学生课堂 |

未登录仍返回 401；其他学生的任务和会话返回 404。老师偏好接口不提供课程，因此保留。旧课程、旧学习记录仍留在数据库供后台和家长历史使用。

教材库模式停止旧的按学生年级准备计划预约、每日自动安排线程、旧课程准备工作线程，并不修改或清除旧任务。学生服务不注入动态生成器。本地管理脚本默认不启动旧课程工作线程。保留 `LEARNING_TEXTBOOK_LIBRARY_ONLY=0` 仅供明确切回旧模式及旧领域回归测试；它不改变当前学生端的教材入口。

## 目录与导学

新增不可变目录修订 `20260924-directory-3`，对应六年制统编一年级语文上册。已对照官方阅读器目录核对“我上学了”、八个单元及 45 个课次，并保留已有第一单元节点身份。官方来源：<https://basic.smartedu.cn/tchMaterial/detail?contentType=assets_document&contentId=1c73b348-e8b6-47d6-84b0-6dbacbe28268&catalogType=tchMaterial&subCatalog=tchMaterial>。

一份学科导学及九份板块导学均预先编写并随目录持久化，共十份。每份包含观察发现、自由选择反馈、生活中的小行动、连接真实课次四步。导学不评分、不写掌握度、不伪造完成记录。朗读可使用设备支持的中文语音；这不是已制作好的 OpenMAIC 配音课堂。

本次只向已有本机开发库追加一个资料修订，不执行结构迁移或数据重置。22 册语文版本索引保留，修订总数由 23 增至 24。导入收据：`output/textbook-student-introductions-20260924/database-import.json`。已确认的旧教材修订仍保持原选择。

**45 是目录课次数，不是正式课件完成数。** 当前十份兴趣导学可体验，正式课件仍待制作与审核；此前第一课仍是私有预览。其他年级目前主要为教材版本索引，不应宣称全国完整课程库已经完成。
