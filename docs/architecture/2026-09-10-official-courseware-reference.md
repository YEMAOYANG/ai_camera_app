# 官方课件交互参考

参考：[透镜课件](https://open.maic.chat/classroom/Nd9W9-NKK5TF7FDdo6VGI)，2026-09-10 实际打开并操作。

## 实际观察

课件包含 7 个场景，编排为基础讲解、光路探索、成像模拟、规律图谱、3D 应用、挑战及归纳。本次实际操作第 3 页“成像全过程动态模拟”，没有验证其他各页的全部操作、语音或讨论质量。

点击“放大镜”前，物距 60、焦距 20，界面显示像距 30、放大倍数 0.50、倒立缩小实像。点击后，物距变为 12、焦距仍为 20，光路画面同步改变，界面显示虚像、放大倍数 2.50、正立放大的虚像。这证明该页面的输入、模型状态、图示和解释是联动的。

本地截图保存在 `output/official-demo-review/01-introduction.png`、`02-simulation-before.png`、`03-simulation-after.png`，均已实际查看；output 不提交到远程仓库。

## 本项目的验收目标

| 参考中的有效设计 | 小学课程对应方式 | 验收依据 |
| --- | --- | --- |
| 改变条件后产生不同结果 | 数学摆数量、拆分组合、调整长度/比例；语言分类、排序或选择材料证据 | 孩子真实操作且独立结果区域发生知识相关变化 |
| 图示、状态和解释一致 | 数量图与算式一致，句序与语义一致，证据选择与理由一致 | 最终冻结页面的浏览器探针、教学审核和服务端合同一致 |
| 从讲解到探索再到挑战 | 示范 → 操作 → 可观察结果 → 理由反馈 → 独立判断 | 每个核心目标有完整映射，独立题不提前泄露答案 |
| 页面形式服从内容 | 按学科和年龄选择必要的模拟、图解、材料或题目 | 不要求所有课强行包含 3D、编程或固定交互页比例 |

新课采用默认适龄深度交互政策。新版政策、创作时实际读取的技能、最终生成产物、浏览器验收和孩子的实际操作分别记录，不能互相代替。原生 OpenMAIC 能承载这类页面；框架支持和代码校验通过并不证明已经生成的三门旧课达到了这个示例的观感与教学质量。

新增课程仍需经过代表性真实生成、触屏与桌面操作、完整学习到报告的验收。当前轮代码检查不调用收费模型，不自动改写或重制原有课程。
