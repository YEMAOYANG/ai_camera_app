# 分年级课程质量升级与单课实测

本轮目标是以官方交互示例为质量参照，完成二至六年级的难度约束和实际画面审核，再生成一门六年级数学样课。三个已有课程和现有家庭数据保留；普通课程生产 worker 保持停止。本记录在实际生成、画面检查和发布后补充真实结果，代码接入本身不代表课件已达到示例质量。

## 代码与合同

- `backend/content/formal_difficulty_policy.py`：基础、标准、挑战三档是显式课程字段；每个知识点仍为三个槽位。题目的运算步骤、证据数量和辨析要求由 Host 确定性核对，不接受仅改难度标签。
- 生成合同把 `difficultyPolicy`、年级边界、课程版本和最终质量证据绑定在一起；旧一年级内容保持历史合同语义。
- Native 补丁 0064：新课每个核心目标具有三至五个可操作状态及复位，分别验证鼠标和触屏路径。分数与百分数使用独立数值和 SVG 几何核对；其他机制明确区分结构、语义与视觉证据。
- Native 补丁 0065：正式渲染的每页 1280×720、1024×768 PNG 进入视觉模型审核。文件、尺寸、截图 hash、最终课程 hash 和审核上下文必须匹配。逐页检查可读性、布局、教学图示、操作入口；失败不能视为通过，也不自动重生成整课。
- Native 补丁 0066：创作工具与最终发布从同一冻结难度规则计算审核缓存身份，语音尾阶段只读取既有通过结果，避免重复收费审核。补丁 0067 在解析前持久化文字和视觉模型的真实原始回复，保留请求身份、内容与 usage，便于定位已付费的解析失败。
- API 不接受客户端自报通过或自选收费模型；操作员单课工具通过现有共享课程、预算、媒体验证和发布服务推进同一课程。人工查看确认是本轮额外验收，不替代真实模型审核收据。

## 模型与费用

创建仍使用 DeepSeek 官方 Pro，文字审核使用 Flash。新增图片审核使用明确配置的 `deepseek-v4-flash-vision-exp`，不自动换供应商。官方图片计费文档给出每图最多 384 tokens 的上界；派发前按该上界加文本字节上界预留，收到供应商 usage 后结算。仅允许已核验的本地 PNG，不接受无法计量的远程图片。

2026-09-10 的实际只读模型列表仅返回 `deepseek-flash` 与 `deepseek-v4-pro`，与文档列举不同。因此先执行了两次小额接口检查：图片模型实际识别官方示例截图中的标题和数值，文字模型返回 OK。两次返回的模型标识均为 `deepseek-flash`；请求模型名和服务返回标识分别记录。按高峰缓存未命中价格保守估算，共 0.001191 元，已在开发库预算账本结算。此次检查未创建课程，也未启动生产 worker。

用户已明确要求删除本样课的人为额度限制。当前 API 采用 `aggregateLimitsEnabled=false`：费用、用量和原授权历史继续记录，人工金额、累计用量及调用次数不再阻断制作，也不通过降低模型、缩减教学内容或跳过质量审核来控制费用。原先生产 8 元、全流程 10 元属于内部自定上限，已停止使用。账本估算仍不等于供应商余额扣款；原始检查记录位于忽略目录 `output/single-course-provider-preflight-result.json`。
