# 一至六年级正式课程链路：代码边界

本记录描述代码实现与隔离验证，不代表新年级内容已生成、完成教研验收或对学生发布。本轮没有启动 worker、没有调用真实模型或创建课程。本地业务库只应用 075–079 结构迁移，原有账号、学习记录和三门课程保留。

## 年级与内容权威

- `formal_curriculum_registry.py` 提供一至六年级显式入口。未知年级、空值、额外空格、外层年级与冻结目标不一致均拒绝，不回落一年级。
- 一年级原始密封题目数据及其 SHA-256 保持不变。二至六年级分别拥有自己的内容契约、数据指纹、Host 收据、语义指纹版本与 canary 清单。
- 一年级 10 个已注册能力点、30 个课程槽；二至六年级各 9 个能力点、27 个课程槽。每个能力点有 3 个变式槽。它们是已注册范围，不代表全年、整册教材或课标完整覆盖。
- 高年级 45 条客观题规则由后端依据公开题干独立求解，模型生成答案与复核模型即使给出同一个错误答案，也不能通过 Host 验证。算式有运算、数值与复杂度限制；转换、几何、分数答案等使用已注册的选择/精确文本格式。
- 作文、主观赏析、无边界阅读推断、发音打分及未注册教材内容保持关闭。有限语文/英语规则只覆盖明示的客观子集，不能作为开放语言理解评分能力的证明。

## 调度、范围与可学库存

- 单个 runner 按配置的年级轮转；同一进程只允许一个 tick 在途。课程构建、模型请求、候选课件均绑定明确年级、目标指纹和租约。费用全站并发仍由统一预算模块负责，不能靠年级轮转代替。
- `LEARNING_CURRICULUM_PREPARATION_GRADE_ALLOWLIST` 默认仍只有一年级。额外年级必须显式列入调度资格，并在 `LEARNING_COURSE_SUPPLY_GRADE_SCOPES` 中配置初始范围或通过授权服务调用建立持久范围。仅注册用户、读取状态、加入调度资格均不建立新的付费范围。
- 旧标量 `LEARNING_COURSE_SUPPLY_SCOPE` 只种下一年级初始范围。后台周期维护刷新既有范围内的优先级，不重新启用已停用课程；需要扩容时显式调用 `request_scope`。同一 owner 的范围替换由数据库行锁串行化。
- 当前指纹存在 owner 后，自动调度不重新领取兼容旧指纹的生产 owner。历史已经发布且仍可学的课，通过精确兼容目标/指纹对继续复用；不会改写其原始目标或重做现有三门首课。
- 有效库存必须同时满足发布、课程启用、课件/课堂就绪、必需媒体齐全以及正式发布证据。候选数、历史发布收据、已撤回课程均不能冒充可学库存；撤回后重新显示真实缺口。

## 对家长端和学生端的状态合同

可信共享摘要包含 `gradeCode`、`targetFingerprint`、`scopeSkills`、`requestedCount`、`readyCount`、`missingCount`、`scopeReady` 和 `availabilityStatus`。`scopeSkills` 仅来自对应年级及指纹下的授权范围或其精确历史兼容范围，不接受前端任意技能列表。

`availabilityStatus` 区分 `empty`、`preparing`、`paused` 和 `ready`；`not_open` 仅表示不支持的年级。二到六年级已允许选择年级、扫码和进入学习空间，没有课程时显示“暂无课程”，不等于年级关闭。共享库是否全部准备好，与某个孩子是否已学完是不同事实。个人 `scope_completed` 必须由个人服务结合对应年级的掌握证据及合法后继课程计算；复习内容应明确标记为复习。

学生真正开放学习仍要求合法会话、明确年级、已发布且媒体齐全的课程和相应访问证据；已有年级代码契约不等于已经有可学课程。

## 数据库升级与验证

`079_learning_multigrade_formal_authority.sql` 原子替换两条旧 CHECK，保留原状态/证据门槛，把固定 30 门改为年级绑定的 30/27 门，同时验证 JSON 年级、总数与课程槽数组。迁移不创建生产范围、不生成内容、不发布课程。历史畸形目标会被拒绝，应按保存的证据处理，不能为了升级而放宽约束。

针对性验证包含：六年级 SQL owner/manifest/canary claim、数据库拒绝跨年级和错误计数、维护不扩回范围、旧 owner 不重开、二/六年级五题 Host 验证和收据重放、45 条规则样例独立求解，以及既有一年级供课与 Host 回归。所有 SQL 验证仅使用被校验为本机 `ai_camera_app_test` 的隔离数据库。

本轮额外运行的历史 preparation repository 全套仍存在旧 V1 年级、旧 120 秒预算、旧 FK/索引与畸形目标晚拒绝的测试假设；这些不能据此宣称全仓测试通过。新规则不应为了兼容旧测试假设而放松。
