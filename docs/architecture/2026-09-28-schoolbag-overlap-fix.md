# 四科书包的重叠与配色修正

数学和英语原先位于同一深度平面，实体封面相交；拿取时尚未清出相邻书本就开始横向和向前运动，进一步产生穿插。第四科加入后，前排书本也遮住了中间两本的书名。

本次仅修改学生端书包的几何、动效和配色：

- `book-layout.json` 统一模型生成和运行时的摆位、封面颜色。数学、英语分处不同深度，前排略低且收在包口内，四科书名完整可见。
- 抽书先沿自己的位置竖直分离，再向前展开；返回走相反路径，先合书和对准位置，再落回。装书也沿各自位置下降，避免横向交叉。镜头跟随初始抬升，封面不会被画面顶部裁切。
- 数学改为蓝色 `#2863b4`，英语改为绿色 `#418448`，同时调整标题底色、书脊、封面板和文字入口；原始插画文件不变。
- 模型更新为 `schoolbag-v5.glb`，84 个网格、85,018 个顶点，无新增纹理下载。旧模型保留。

验证：Student Web lint、TypeScript、256 项测试、生产构建通过。新增几何回归检查读取实际 GLB，对四本书的静止、悬停、打开/返回各 201 个采样点检查包围盒相交，并检查归位和封面展开顺序。数学标题/底色对比度约 7.98，英语约 6.79。

真实渲染器已逐帧目视检查数学、英语，并验证四本书的射线点击对应正确学科。生产预览使用独立合成浏览器会话与仓库已有教材数据，在 1366 × 960、375 × 812 下打开和放回数学、英语，核对精确教材 URL、减弱动画和无横向溢出。无实际家庭数据写入，未触发课程生成。本次未改家长 App 或后端数据库。
