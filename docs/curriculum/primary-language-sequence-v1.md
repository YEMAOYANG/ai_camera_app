# Mira 小学语文与英语循序学习体系 v1

状态：六年课程主线设计；尚未展开为全部课次或接入运行时。与[课程体系及连续学习规则](../architecture/2026-09-16-progressive-primary-curriculum.md)配套使用。这是 Mira 自建顺序，不宣称与指定教材、学期考试或官方课标逐项同步。

`ZH1A01` / `EN1A01` 表示语文/英语、一年级、上阶段、第一个单元；B 表示下阶段。箭头表示教学小步骤的推荐顺序，每一步仍须展开课次、知识 ID、真实前置、教学材料和独立验证。上下阶段不按日期强制推进。朗读、口语和写作纳入课程目标，但现有客观题判分不能代替这些能力的实际评估。

## 语文一年级上阶段：拼音入门与完整拼读路径

| 单元 | 教学小步骤 |
| --- | --- |
| ZH1A01 听音与单韵母 | 口形与声音 → a、o、e → i、u、ü → 单韵母四声 |
| ZH1A02 第一组声母与二拼 | b、p → m、f → d、t、n、l 分组 → 与已学韵母简单两拼 |
| ZH1A03 第二组声母与拼写变化 | g、k、h → j、q、x → y、w → ü 与 j、q、x、y 相拼时的书写变化 |
| ZH1A04 平舌与翘舌 | z、c、s → zh、ch、sh、r → 已教音节中的辨听 → 看拼音、听音与跟读匹配 |
| ZH1A05 复韵母与标调 | ai、ei、ui → ao、ou、iu → ie、üe、er → 与已学声母拼读 → 标调位置 |
| ZH1A06 鼻韵母、整体认读与三拼 | an、en、in、un、ün → ang、eng、ing、ong → 分组整体认读 → 简单三拼 → 混合辨认拼读 |

整体认读音节材料清单覆盖：zhi、chi、shi、ri、zi、ci、si、yi、wu、yu、ye、yue、yuan、yin、yun、ying。鼻韵母、整体认读和三拼应各拆多个课次，不能一节课教完，也不能一题代表整组掌握。后续细排可将某些整体认读音节安排在相关声母/韵母之后即时教学，但必须保留独立教学与验证节点。

## 英语一年级上阶段：分组学习 26 个字母

| 单元 | 教学小步骤 |
| --- | --- |
| EN1A01 A–E | A、B 与 C、D、E 分课辨认 → 大小写 → 字母名 → 已示范词中的常见声音 |
| EN1A02 F–J | F、G 与 H、I、J 分课 → 大小写 → 与 A–E 混合辨认 → 本组常见字母音 |
| EN1A03 K–O | K、L 与 M、N、O 分课 → 大小写 → 易混字形 → 已示范词的对应首音 |
| EN1A04 P–T | P、Q 与 R、S、T 分课 → 大小写 → 混合定位 → 常见声音 |
| EN1A05 U–Z 与整合 | U、V、W 与 X、Y、Z 分课 → 大小写混合 → 顺序与缺失定位 → 字母名与词中声音区别 |

每组继续拆为多节课。字母音在选定词表中学习，不能教成“一个字母永远只有一种读音”；听过示范词不等于具备该词独立读写能力。26 个字母各自保留认读与大小写等证据，不能用整组测验的两道题代替全部掌握。

| EN6B02 简短交流 | 任务信息 → 提问澄清 → 选择理由 → 确认理解 |
| EN6B03 多材料阅读 | 消息日程说明 → 人物时间对齐 → 差异冲突 → 有依据回答 |
| EN6B04 短段写作修改 | 对象目的 → 顺序要点 → 已学词句成段 → 时态指代拼写连贯检查 |
| EN6B05 综合任务 | 受控任务说明 → 听读取信息 → 口头或书面成果 → 薄弱技能回补 |

本主线不默认引入现在完成时、被动语态、复杂从句等；不能以“六年级挑战题”为由自动添加。这里的五年级过去时、四年级进行时等是新设计顺序，不能与旧生成权威中的年级安排混用，必须通过新体系版本整体接入。

## 跨年级衔接与生产约束

| 主线 | 必要前置摘要 |
| --- | --- |
| 语文识读 | 拼音细知识 → 受控字词 → 句子 → 短段；识字、书写、听理解分别保存证据，不能互相替代 |
| 语文阅读 | 短段显性信息 → 中心与支撑 → 结构与因果 → 单步推断 → 观点证据 → 多文本整合 |
| 语文表达 | 口述完整句 → 连贯短段 → 事件结构 → 具体描写 → 分段选材 → 有目的表达与多轮修改 |
| 英语形音 | 字母形名音 → 受控拼读与高频词 → 拼读模式拓展；一个词的听理解不等于独立认读或拼写 |
| 英语语法 | 基本句型 → 一般现在时 → 第三人称和助动词 → 进行时及对比 → 过去时 → 将来表达 → 综合运用 |
| 英语阅读表达 | 已教词汇句型 → 显性信息 → 顺序短段 → 说明与比较 → 时间线 → 多材料与证据 |

拼音、字母、词汇、语法和阅读的前置须落到细知识 ID。不能把“完成一个单元”自动等价于其中全部知识掌握。新课可以明确教授未学词语，但不能在教授前依赖它考核；游戏文字、旁白、示范和题目同样受控。

高年级新孩子先验证必要基础，已会的依证据跳过，缺哪部分补哪部分。各科进度独立；看完、点击过关和提示答对不能代替独立证据。每一小步骤都具备初学、引导、独立验证、补救与延后复习的路径。
