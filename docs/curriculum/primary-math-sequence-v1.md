# Mira 小学数学循序学习体系 v1

状态：六年课程主线设计；尚未展开为全部课次或接入运行时。与[课程体系及连续学习规则](../architecture/2026-09-16-progressive-primary-curriculum.md)配套使用。这是 Mira 自建顺序，不宣称与指定教材、考试进度或官方课标逐课同步。

`M1A` 表示一年级上阶段，`M1B` 表示下阶段，其余类推。箭头表示单元内教学小步骤的推荐顺序；每一步必须展开为明确的知识目标、前置关系、教学与评估课次，不能把整个单元当作一节课。几何、测量和数据可以并行，只检查真实需要的前置知识。

## 一年级上阶段：数量、数字与运算意义

| 单元 | 教学小步骤 |
| --- | --- |

| M1A04 10 以内加减法 | 合并物体理解加法 → 拿走与剩余理解减法 → 从实物图写算式 → 理解加减关系 → 解决一步生活问题 |
| M1A05 位置与基本形状 | 上下前后 → 明确视角的左右 → 常见平面图形与立体物体 → 按单一特征分类 |

## 必须登记的前置链

| 模块 | 必要前置关系 |
| --- | --- |
| 数与加减 | 一一对应数数 → 总数意义 → 数字对应 → 数的组成 → 10 内加减 → 十进制数位 → 进退位 |
| 乘除 | 相同数量分组与加法 → 乘法 → 平均分与乘除关系 → 除法 → 余数 → 多位数乘除 |
| 分数 | 平均分 → 单位分数 → 几分之几 → 同分母运算；等值分数、约分、通分 → 异分母加减；分数乘法 → 分数除法 |
| 比与百分数 | 除法与分数意义 → 比；分数小数互化及乘除 → 百分数；比 → 比例 |
| 长度与周长 | 长短比较 → 等长单位连续测量 → 标准单位；长度测量与加法 → 周长 |
| 面积 | 单位覆盖、行列计数与乘法 → 长方形面积 → 剪拼 → 三角形梯形与组合面积 |
| 体积 | 单位立方体、长宽高及乘法 → 长方体体积；圆面积与底面积乘高 → 圆柱 → 圆锥 |
| 时间 | 活动先后 → 整时半时 → 时分关系 → 经过时间 → 日期问题 |
| 数据 | 分类计数 → 表与图画图 → 条形图；连续变化 → 折线图；百分数 → 扇形图 |
| 方程 | 未知量、四则关系与等号 → 等式平衡 → 一步方程 → 两步方程 |
| 比例应用 | 比和比例加具体数量概念 → 比例尺及正反比例应用；速度问题还需单位时间量 |

这些是单元级前置摘要；生产前必须展开为知识 ID 之间的无环图。不能仅凭本表完成跨课校验。

每单元都配同目标补救、不同题目的独立检查及延后复习。复杂的计算方法不能只展示一遍便进入综合题。生成挑战课时只组合已学知识，不越过下一单元的必要教学步骤。
