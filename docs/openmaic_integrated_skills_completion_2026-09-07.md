# OpenMAIC 自动课程技能整合与讨论完成修复

本轮承接：把 Pro 的创作能力用于 Mira 自动课程生成，保持现有学生端入口；排查《冬阳广场里的数位探险》停在 95% 的原因。

## 自动生成

路径继续为家长设置年级 → 后端准备课程 → OpenMAIC Pro Agent 创作 → 正式课件、引用、媒体与语音校验 → 学生端上课。学生不需要打开独立工作台，也不需要自己编写提示词。

新创建的正式课件生成任务采用 `mira-primary-integrated.v1`，默认组合：

- `mira-primary-courseware`：Mira 小学正式课程的边界与页面要求。
- `stage-design`：单节课堂规划与生成流程。
- `k12-core-literacy-planning`：核心素养、学习动作与观察证据，并读取基础及对应学科参考。
- `deep-interactive`：有意义的操作、可观察变化和反馈。
- `slide-craft`：页面排版、可读性及视觉检查。
- `learning-to-learn`：每课嵌入 1–2 个预测、回忆、自我解释或检查理解的动作。

正式课程合同优先：不额外询问计划确认，不改锁定的题目/选项，不强行套用 60% 交互页比例或固定页数。个人技能提炼、系列课程规划及其他互相冲突的教学风格不默认全部启用。联网研究沿用已有 1–4 次搜索、实际抓取和引用校验；图片继续按教学需要使用 Qwen。

主 Agent 必须实际读取六个内置 Skill 与两个学科参考。逐页内容、讲解生成请求都会收到适用的原文规则，不依赖主 Agent 自行转述。只有真实生成调用和页面持久化成功后才记录应用证据；缺失任一页的内容或讲解上下文记录会拒绝新版正式完成回执。

证据包含完整来源 SHA256、每页内容/讲解上下文 SHA256、嵌套和父级回执 SHA256，绑定同一会话、课堂和页面。该证据证明加载与生成上下文的使用，**不等于最终教学质量认证**；Agent 后续对同一页的修订仍允许，正式结构、引用及音频门禁继续校验最终课件。
