## 学生端中的使用方式

家长保存年级后，后端生成新课程时使用 Pro 制课能力。学生继续从学习目录上课，无需进入 Pro 工作台、输入技能命令或选择模型。

新流程是：锁定学科和年级知识边界 → 自动选技 → 阅读技能全文 → 检索教学资料 → 规划和生成页面、练习与讲解 → 打开实际页面并操作 → 独立检查教学内容 → 必要时读取编辑技能修订 → 检查最终课件 → 生成和验证语音 → 发布。

“精品”是生成和验收的目标。自动检查不能证明学生已经学会，也不能保证不同主题生成的页面与官方某一份 Demo 逐像素相同。

## 技能什么时候使用

选技注册表覆盖当前 23 项内置技能，每项记录选用、不适用或延后使用的原因。选择依据包括实际教学目标、允许内容和教学任务，不只匹配课程标题。

| 技能 | 自动使用的环节与条件 |
| --- | --- |
| 小学制课、课堂设计、K12 核心素养、深度交互、幻灯片设计、学会学习 | 新版正式课程的基础组合；内容与讲解生成都会获得适用正文 |
| 理解为本的教学设计（UbD） | 从学习目标与测验要求倒推活动和解释 |
| 费曼学习法 | 目标确实需要理解概念、解释关系，且本节允许内容和教学任务能够支持解释循环 |
| 工作坊式教学 | 目标以操作、读写、练习等任务为主；与费曼法择一作为主要教学方法 |
| 社会情感学习 | 目标和具体教学情境都明确涉及合作、倾听、换位思考等 |
| 深度调研 | 目标和教学材料确实依赖外部或时效性事实；普通课程仍执行正式联网检索和来源校验 |
| Pro 编辑、课堂 DSL、幻灯片 DSL | 质量检查发现问题后自动读取，修订已有页面；幻灯片 DSL 按问题所涉及的页面类型使用 |
| 原样导入、页面/风格复刻、教师风格复刻 | 当前自动制课没有授权的参考课件或教师资料，因此不虚构参考来源 |
| 系列规划、螺旋课程、创建个人技能 | 当前任务是单节课，也没有对应的跨课历史/个人技能创建任务，因此不扩展成另一个任务 |
| 密集讲座、职业教育 | 不符合当前小学正式课程合同 |

基础技能按阶段参与：规划约束进入课堂设计，页面设计和交互要求进入内容生成，讲解、提问与学习方法进入动作生成。选技计划、完整正文读取记录及逐页上下文哈希都会留下回执。技能文件可读取不等于已经成功用于课件；最终页面仍必须通过检查。

费曼法要求给真实学习者解释的机会，再帮助其修正并再次解释。虚拟同伴代替学生说出答案，不能算作学生已完成解释；本次未宣称新增了逐句口述自动诊断能力。

## 年级和教学质量

后端将完整课程边界传给最终制课环节：年级、学科、技能、学习目标、允许内容、排除内容、先修要求、语言、建议时长和边界版本。Runtime 和后端分别核对其内容及哈希。

最终教学检查覆盖七个方面：年级匹配、目标覆盖、教学顺序、误解纠正、有意义的交互、测验对齐、语言负担。检查者必须引用实际页面或讲解中的原文，不能只返回一个“合格”标签。每个学习目标都需要对应的页面证据。

四道正式测验题的文字、选项和身份由后端锁定。新版保留其在教学流程中的位置，拒绝改题、漏题和模型自行写入评分权威。题目和引用在审查工具及最终发布阶段使用相同的规范化处理；后续编辑使原审查失效。

浏览器以 1280×720 和 1024×768 两种尺寸打开所有页面，检查实际渲染、资源错误、文字裁剪和可操作状态，并保存截图。交互页需要有可观察的本地操作变化。使用真实幻灯片、测验和 PBL 组件；验收专用只读环境阻断答题持久化、导师自动调用和业务提交。

当前独立检查使用已配置的 DeepSeek 文本模型，接收页面源码、文字和浏览器观察结果；它没有看图能力。截图供复核，不能把它的文本结论称作视觉模型验收。

同一课程最多进行三次质量审查尝试；每批独立模型审查遇到 HTTP 429 时沿用一次有限重试，不能把“三批”解释为全课程只有三次模型 HTTP 请求。相同的已审查内容复用结果；未完成或结果不明的旧尝试不会因恢复而自动重复派发。用完预算仍不合格时停止发布。正式 Pro 会话仍保留 60 分钟等待上限；超时会请求取消该会话，由持租约的运行端中止后续工作。这不是全课程金额或 token 的硬上限，也不代表已发送的请求不计费。极大的课件可能超时并停止发布。

## 媒体与 Pro 能力

联网搜索、资料读取、页面生成、互动编程、逐页编辑和修订都发生在后台生成阶段。学生端保持现有课堂入口。

图片沿用已接入的 Qwen Image，按教学需要生成。精确的数量、文字、公式与几何关系仍由可核对的页面元素或 HTML 表达，不能依赖图片模型画对。视频能力取决于可用的视频 Provider 配置；本次未以动画或静态图冒充已完成视频生成。MAIC-UI 未集成。

## 升级与验收边界

新建目标使用 `mira-primary-adaptive.v2`。三个历史制课合同保留原始内容和指纹，已发布课件不会因升级而自动重制。默认自动调度包含新版和升级前的固定六技能版，保留原先的排队范围。更早的图片版、无图版合同仍可用于显式恢复或已经派发任务的查询核实，但不会因升级自动唤醒历史付费计划。已失败、已终止或结果不明的任务不会重新派发。

课程边界注册表包含小学多个年级；当前正式学生发布范围仍为已开放的一年级。这次不将“存在边界配置”当作其他年级已经通过上线验收。

## 本机构建说明

本次在独立候选目录离线安装了锁定依赖，没有下载或升级依赖版本。上游 renderer/editor 的 Rollup CLI 在本机 Node 25 和 bundled Node 24 都出现输出完成但不退出的情况；使用相同 Rollup 配置的临时脚本依次等待 `write` 和 `close` 成功、再生成 TypeScript 声明并同步 importer，之后 Next Webpack 正式构建通过。没有将挂起的 CLI 当成构建成功，也没有修改 renderer/editor 源码。实际使用的 [临时构建脚本](../output/openmaic-adaptive-quality-2026-09-07/rollup-once-workaround.mjs) 留作证据；该脚本限定本次候选目录，不是通用安装入口。
