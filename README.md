# Mira Guardian（米拉）家长端 App

Mira Guardian（米拉）家长端 App 是 AI 智护摄像头产品的家长管理入口。这个 App 只面向家长使用，用来完成设备绑定、孩子档案、一日流程、任务计划、实时看护、报告、积分、打卡、安全告警、隐私设置和家庭成员管理。

本 README 只描述家长端 App 的产品功能、页面内容、MVP 范围和开发计划。更完整的需求来源见 [docs/ai_camera_parent_needs_product_tech_plan.md](docs/ai_camera_parent_needs_product_tech_plan.md)。

当前仓库还没有初始化 Flutter 工程，本文档先作为家长端 App 的研发入口。

## App 定位

家长端 App 的核心目标是帮助家长低成本掌握孩子一天的状态，并把“反复催促、远程看护、任务管理、学习陪伴、安全提醒、成长记录”这些家庭高频需求收进一个可操作的界面里。

App 首页需要优先回答三个问题：

1. 孩子现在是什么状态？
2. 今天的任务和一日流程完成得怎么样？
3. 有没有需要家长立即处理的事情？

首版 App 不做孩子端娱乐入口，不把孩子引导到手机里长时间操作。孩子主要通过摄像头语音互动，家长通过 App 管规则、看结果、处理异常。

## 目标用户

| 用户 | 需求 | App 价值 |
|---|---|---|
| 父母 | 想知道孩子是否按时学习、吃饭、休息、睡觉 | 首页状态、一日流程、日报、实时看护 |
| 主要照护人 | 需要设置提醒、积分、任务和安全规则 | 任务计划、流程模板、积分规则、紧急联系人 |
| 异地家长 | 不能一直在孩子身边，但想及时知道异常 | 推送、实时看护、事件摘要、安全告警 |
| 共同照护成员 | 需要查看有限信息或协助处理任务 | 家庭成员权限、角色管理、通知分发 |
| 祖辈/保姆 | 需要按家长规则协助照护，但不需要看到全部隐私 | 待办交接、有限权限、事件处理记录 |

## 核心功能

### 首页

首页是家长打开 App 后的主看板，需要简洁展示“当前状态 + 今日进度 + 待处理事项”。

内容包括：

- 设备在线状态、隐私模式、当前家庭场景。
- 孩子当前状态：学习中、休息中、离座、吃饭、睡前流程、未知等。
- 今日一日流程完成率。
- 今日任务列表和最近一项任务状态。
- 最新提醒、异常事件和需要家长确认的事项。
- 实时看护、报告、安全事件的快捷入口。

首页不应堆满所有数据，而是把真正需要家长处理的内容放在最前面。

### 设备绑定与家庭管理

家长端需要支持完整的首次使用流程。

内容包括：

- 登录或注册。
- 扫码绑定设备。
- 设备命名和房间位置设置。
- 家庭成员邀请。
- 成员角色：管理员、监护人、临时查看者。
- 设备解绑、转移和异常离线提示。
- 家庭协作待办：安全事件、打卡审核、任务纠正、奖励兑换审批可分配给具体照护人。
- 处理记录：记录谁在什么时间处理了什么事项，避免多位家长重复处理或漏处理。

### 孩子档案

孩子档案用于调整提醒语气、任务时长、学习内容和安全策略，只收集必要信息。

建议字段：

| 字段 | 是否必填 | 用途 |
|---|---|---|
| 孩子称呼 | 必填 | 语音互动、报告称呼 |
| 年龄段 | 必填 | 语气、任务时长、安全等级 |
| 年级 | 学习功能开启时必填 | 题目辅导、学习报告 |
| 作息时间 | 建议填写 | 起床、吃饭、学习、睡觉提醒 |
| 紧急联系人 | 安全功能必填 | SOS 和异常告警 |
| 教材版本 | 可选 | 后续学习诊断 |
| 兴趣偏好 | 可选 | 故事、陪伴话题 |

性别不建议作为必填项，核心功能不依赖性别。

### 一日流程

一日流程是家长端最核心的功能之一。它不是单个闹钟，而是把孩子一天中连续发生的事情整理成可执行流程。

模板包括：

- 上学日。
- 周末。
- 假期。
- 考试周。
- 睡前流程。
- 带书/物品清单。
- 自定义流程。

流程项示例：

| 时段 | 流程项 | 家长端展示 |
|---|---|---|
| 早晨 | 起床、洗漱、早餐、带书包 | 上学准备进度 |
| 放学后 | 回家、喝水、整理书包、休息 | 放学后状态切换 |
| 作业前 | 清桌面、准备文具、选择任务 | 第一项任务准备情况 |
| 作业中 | 专注计时、休息、不会题求助 | 学习状态和求助记录 |
| 晚饭后 | 家务、收玩具、兴趣任务 | 家务完成和积分 |
| 睡前 | 洗漱、收书包、故事、关灯 | 睡前流程完成率 |
| 前一晚/早晨 | 带课本、运动服、手工作业 | 今日物品清单 |

家长端能力：

- 创建流程模板。
- 从模板生成当天流程。
- 临时调整某天流程。
- 查看每个流程项状态。
- 对卡住的流程项进行延后、跳过、完成或提醒。
- 在日报中查看流程完成图。
- 根据课程表生成“明天要带什么”，前一晚和早晨各提醒一次。
- 支持家长手动添加临时物品，例如雨伞、校服、证件照、手工作品。

### 任务计划

任务计划用于具体管理每天要做的事情。

任务字段：

| 字段 | 示例 |
|---|---|
| 任务名称 | 数学作业 |
| 任务类型 | 学习、家务、吃饭、洗澡、睡眠、打卡 |
| 日期/重复 | 周一至周五 |
| 开始时间 | 19:00 |
| 预计时长 | 25 分钟 |
| 休息规则 | 25 分钟学习 + 5 分钟休息 |
| 积分 | 完成 +5 |
| 检测方式 | AI 判断、家长确认、手动完成 |
| 提醒方式 | 摄像头语音、App 推送、仅记录 |
| 证据要求 | 无、截图、短视频、家长确认 |

任务状态：

```text
scheduled -> due -> pending_start -> running -> completed
                         |               |
                         v               v
                      delayed         paused
                         |
                         v
              needs_parent_attention
```

家长端操作：

- 新建任务。
- 批量创建一周任务。
- 暂停、延后、跳过、完成。
- 查看任务开始证据和提醒次数。
- 对 AI 判断结果进行纠正。
- 查看任务完成证据，例如作业桌面截图、家务前后对比、打卡视频。
- 对任务结果进行确认、驳回或改判，纠正结果进入日报和积分流水。

### 任务证据与确认

任务证据用于降低误判，也让家长知道孩子不是“被 AI 扣分或加分”，而是有可解释的完成依据。

适用场景：

- 作业：截图、专注轮次、离座次数、求助记录。
- 家务：整理前后截图或短视频。
- 打卡：照片/视频素材和家长审核结果。
- 睡前流程：洗漱、收书包、上床等流程节点。

家长端能力：

- 查看证据缩略图、时间、触发规则和置信度。
- 一键确认完成、驳回、改为部分完成。
- 撤销自动加分或发起手动补分。
- 标记误判原因，用于后续规则优化。

### 专注计时

专注计时服务于学习和练习场景。

默认模式：

- 25 分钟学习 + 5 分钟休息。
- 低龄儿童可选 15/5 或 20/5。
- 家长可配置长休息。
- 支持任务中途暂停和延后。

App 展示：

- 当前专注轮次。
- 剩余时间。
- 是否离座。
- 是否出现坐姿提醒。
- 休息是否结束。
- 本次任务是否超时。

### 睡眠与晨起

睡眠与晨起用于回应家长对“几点睡着、有没有睡、早上能不能叫起床”的需求。首版只做家长端可理解的基础记录，不做医疗化判断。

页面内容：

- 今晚睡前流程状态。
- 上床时间、疑似入睡时间、起床时间。
- 夜间醒来、长时间未睡、异常声音提醒。
- 晨起闹铃状态：待响、已响、已延后、已起床。
- 睡眠日报入口，展示入睡时长、夜醒次数和作息趋势。

家长端操作：

- 设置睡觉时间、起床时间、午睡时间。
- 设置晨起提醒音量、延后次数和是否需要家长确认。
- 设置夜间免打扰，只保留安全事件和异常声音通知。

### 实时看护

实时看护用于家长主动查看孩子当前状态。

页面内容：

- 实时画面入口。
- 设备在线和隐私状态。
- 音频通话按钮。
- 截图按钮。
- 云台方向控制。
- 常用视角预置位：书桌、床、门口、玩具区。
- 最近事件列表。
- 事件回放入口，查看安全、任务、睡眠、打卡等事件的短片或截图。

隐私要求：

- 家长查看实时画面时，App 要提示设备端会显示工作状态。
- 隐私模式开启时，实时看护入口应明确不可用或受限。
- 家长可以设置“只保存事件截图，不保存连续录像”。

### 报告

报告页让家长快速理解孩子一天和一周的状态。

日报内容：

- 今日摘要。
- 一日流程完成情况。
- 任务完成/未完成/超时。
- 坐姿、专注、离座、休息记录。
- 积分变化。
- 学习求助摘要。
- 对话摘要。
- 睡眠与晨起摘要。
- 带书/物品清单完成情况。
- 任务证据和家长确认记录。
- 安全和异常事件。
- 成长时刻精选。
- 明日建议，最多 1-3 条。

周报内容：

- 本周任务完成趋势。
- 专注时长和按时开始趋势。
- 坐姿提醒和离座趋势。
- 高频学习求助类型。
- 作业依赖风险：是否频繁问同类题、是否跳过思考直接求助。
- 睡眠趋势：入睡时间、起床时间、夜醒趋势。
- 家庭协作处理情况。
- 积分变化。
- 家长需要关注的 1-3 个问题。
- 下周建议目标。

报告页原则：

- 先给结论，再给明细。
- 不制造焦虑，不使用“落后、失败、糟糕”等评价词。
- 支持展开查看证据截图、事件时间线和对话摘要。

### 积分

积分系统是家长用来正向激励孩子的工具。

功能包括：

- 今日积分总览。
- 积分流水。
- 加分规则。
- 兑换奖品。
- 家长手动调整。
- AI 自动加分后的撤销入口。
- 奖励商店：家长设置奖品、所需积分、兑换限制和有效期。
- 兑换审批：孩子发起兑换后，家长确认发放。
- 兑换记录：记录奖品、积分、审批人和兑现状态。

原则：

- 少扣分，多鼓励。
- 自动扣分默认关闭。
- 兑换奖励由家长设置，App 不主动承诺孩子奖励。
- 奖励不只绑定学习，也可以绑定收纳、按时起床、独立完成流程等习惯。

### 成长时刻与事件回放

成长时刻用于保留值得回看的积极片段，事件回放用于帮助家长快速判断发生了什么。

内容包括：

- 第一次独立完成任务。
- 连续专注、按时开始、主动整理、睡前流程完整完成。
- 家长标记的重要照片或短视频。
- 安全事件、离座事件、打卡事件的回放入口。

原则：

- 默认只保存精选片段和事件证据，不保存全天连续录像。
- 家长可以收藏、删除、分享或隐藏某个成长时刻。
- 成长时刻优先强化积极行为，不把孩子的失误做成公开展示。

### 打卡助手

打卡助手用于学校、兴趣班或家庭任务的照片/视频素材准备。

MVP 范围：

- 创建打卡任务。
- 接收摄像头采集的照片或视频素材。
- 家长审核素材。
- 保存到相册或分享给其他 App。
- 记录打卡完成状态。

首版不做第三方学校平台自动提交。

### 对话与人设设置

家长可以管理孩子和摄像头的互动边界。

功能包括：

- 设置孩子称呼。
- 设置摄像头唤醒名。
- 选择原创声线。
- 设置自由聊天单次时长。
- 设置每日总聊天时长。
- 设置故事、音乐、音频通话的可用时段。
- 设置提醒频率、冷却时间和免打扰时段。
- 开启或关闭普通闲聊摘要。
- 查看学习、情绪、安全等分类对话摘要。
- 开启逐字记录时必须有明确提示。

对话记录默认策略：

| 类型 | 默认展示 |
|---|---|
| 普通闲聊 | 主题摘要和时长 |
| 作业辅导 | 题目、引导过程、结果摘要 |
| 情绪表达 | 摘要和关注标签 |
| 安全事件 | 原文、音频片段、事件证据 |

互动边界默认规则：

- 作业模式中只允许任务相关问答。
- 睡前模式中不主动开启长时间自由聊天。
- 免打扰时段内只保留安全告警、晨起闹铃和家长主动通话。
- 孩子频繁问同类题时，日报中标记“可能依赖 AI 求助”，建议家长关注。

### 安全告警

安全模块用于高优先级事件处理。

页面内容：

- SOS 事件。
- 陌生人或敲门提醒。
- 危险区域提醒。
- 异常声音提醒。
- 家长异常求助。
- 安全区域规则：门口、厨房、窗边、阳台、楼梯等。
- 紧急联系人。
- 事件处理状态：待处理、已联系、已解决、误报。
- 处理人和处理时间。

告警流程：

1. App 收到安全推送。
2. 进入安全事件详情。
3. 查看事件摘要、截图、音频或短视频。
4. 一键发起音频通话。
5. 指派或记录处理人。
6. 标记处理结果。
7. 必要时通知第二联系人。

### 隐私与权限

隐私设置是家长端的基础能力。

功能包括：

- 隐私模式开关。
- 远程查看提示设置。
- 对话记录保存策略。
- 照片、视频、报告删除。
- 家庭成员权限。
- 儿童数据导出和删除入口。
- 推送通知开关。

## MVP 范围

第一版家长端 App 建议聚焦以下闭环：

1. 登录、家庭创建、设备绑定入口。
2. 孩子档案创建和编辑。
3. 首页状态看板。
4. 一日流程模板和今日流程。
5. 带书/物品清单。
6. 每日任务、任务证据和专注计时。
7. 睡眠与晨起基础卡片。
8. 实时看护和事件回放页面。
9. 日报页面。
10. 积分流水、积分规则和奖励商店。
11. 打卡素材审核。
12. 对话摘要、人设设置和互动边界。
13. SOS、安全事件处理和紧急联系人。
14. 隐私模式、权限和通知设置。

暂缓到后续版本：

- 多孩子复杂切换。
- 多设备联动。
- 完整学习缺漏诊断。
- 第三方学校平台自动提交。
- 高级家庭成员审计。
- 长期成长档案导出。
- 睡眠趋势高级分析。
- 危险区域自动规则推荐。

## 核心状态模型

| 模型 | 说明 |
|---|---|
| `User` | 当前登录家长 |
| `Family` | 家庭空间 |
| `FamilyMember` | 家庭成员、角色、权限 |
| `ChildProfile` | 孩子称呼、年龄段、年级、作息偏好 |
| `Device` | 设备名称、在线状态、隐私模式、位置 |
| `DailyFlowTemplate` | 上学日、周末、假期、睡前等流程模板 |
| `DailyFlowRun` | 当天流程执行状态 |
| `PackingList` | 课程表带书和临时物品清单 |
| `TaskTemplate` | 可复用任务模板 |
| `TaskRun` | 当天任务执行状态 |
| `TaskEvidence` | 任务截图、短视频、确认状态和误判原因 |
| `FocusSession` | 专注计时记录 |

## 隐私与合规原则

- 收集、使用、上传儿童音视频前必须获得监护人授权。
- 普通对话默认展示摘要，不默认展示全部逐字记录。
- 家长开启逐字记录时，App 必须明确提示用途和保存周期。
- 家长可删除照片、视频、对话摘要、逐字记录和报告。
- 家长可删除成长时刻和任务证据，安全事件证据按合规策略保留最小必要内容。
- 家庭成员按角色授权，避免非监护人查看敏感数据。
- 远程查看、通话、录像和记录模式需要清晰的 App 提示。
- 隐私模式开启后，实时看护和记录入口必须明显受限。
- 睡眠、成长时刻和家庭协作记录都应支持分级权限。
