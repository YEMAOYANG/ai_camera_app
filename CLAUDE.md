# Mira project instructions

Apply the shared project instructions:

@AGENTS.md

For textbook course authoring, review or revision, the current interaction rules
are the following project sources. Read the complete policy before planning or
changing a lesson:

@docs/learning/low-reading-interaction-rule.md
@backend/content/textbook_interaction_policy.v1.json

For a new workbench job, supply the structured `scopeReview`, ordered `pagePlan`
(page, type, title, teaching move), `qualityRules`, and `lockedAssessments` as
well as the request. The v3 job freezes these with the catalog, teacher and
interaction policy in `sceneContract`; the native page generator must consume
that exact contract. Low-reading quiz choices need stable picture asset keys.
Optional quiz narration beyond the exact question must be reviewed in that
page's `narrationGuidance`. Do not narrate the answer explanation before a choice.

Generated speech, pictures and scenes remain candidates: verify cue-to-speech
bindings and actual asset bytes, preserve the candidate receipt, then check
meaning, gameplay and real audio independently. A valid receipt does not prove
image semantics, game diversity or learning mastery. Check that the deployed
native runtime has the matching numbered patch before dispatching v3 jobs.

The accepted 《金木水火土》 v7 remains a quality example for textbook alignment,
meaningful pictures and teacher narration. It is not a fixed page-count,
renderer-order or game-mechanism template. The current policy governs new
authoring and explicitly authorized revisions within its stated precedence.

Inspect the actual job's frozen policy and request before saying the rules were
applied. These instruction imports do not change a running job, upgrade a legacy
formal contract, prove play quality or authorize publication. For existing
course repairs, preserve the original revision and evidence, keep the exact
textbook and teacher scope, and use an explicit revision or authorized follow-up
with recorded review. Never overwrite frozen requests or paid receipts to make
an old job appear to have used the new rules.
