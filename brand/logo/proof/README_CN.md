# 暖瞳 WarmSight 附件原图锁定包 v2

本包以本次对话中提供的四张附件图片作为唯一视觉母版。

## 处理原则

1. `00_Original_Attachments` 为附件原图的逐字节复制。
2. `01_PNG_CreamBG_1024` 仅从 1254 x 1254 等比例缩放到 1024 x 1024；没有重绘、自动描摹或拉伸。
3. `02_PNG_Transparent_1024` 仅去除近似暖米白背景；图形轮廓没有重新生成。
4. `03_PNG_Transparent_Trimmed` 只裁掉外围空白，不改变比例。
5. `04_Icon_Sizes` 只基于附件中的独立图形等比例导出常用尺寸。

## 重要说明

- 视觉权威文件是 `00_Original_Attachments` 和 `01_PNG_CreamBG_1024`。
- 本包不把自动描摹结果冒充真正矢量 Logo。自动描摹会改变曲线、叶片、瞳芯和文字笔画。
- 真正可编辑的 SVG / AI / EPS 母版需要人工逐段重建贝塞尔曲线，并与附件叠加校对。
- 纯文字版、横版、竖版分别直接来自对应附件，并非重新拼版。

## 推荐用途

- 官网、海报、提案、社媒：使用暖米白背景 1024 PNG。
- 透明背景排版：使用 Transparent 版本，并在深浅背景上检查边缘。
- App / 头像：使用 `04_Icon_Sizes`。
- 大幅印刷、设备丝印、商标注册：确认视觉母版后再制作人工矢量母版。
