# 暖瞳字体与排版规范

## 字体策略

Flutter App 中文优先使用系统字体，不在当前阶段引入额外字体包。这样能保持 iOS / Android 渲染稳定，也避免字体授权和包体积风险。

## 层级

- 页面标题：清楚、稳重、短句，避免营销腔。
- 区块标题：用于作息、看护、任务、提醒等模块，保持可扫读。
- 正文：短句优先，减少长段解释。
- 按钮：使用明确短动词，如“添加”“查看”“保存”“确认”。
- 辅助说明：用于隐私、连接、离线、异常状态，不展示内部 API 或调试语言。

## 语气

家长端文字应温和、准确、可行动。避免后台系统词、设备工程词和过度 AI 化表达。
